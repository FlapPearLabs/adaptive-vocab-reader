## 下一步：Ticket 03（首测词汇量估计展示）
- 文件：`work/tickets/2026-07-31-v0.1-realign/03-vocabulary-estimate.md`（Status: ready-for-agent；Blocked by 02 已解除）。
- 主责任：R-EST-1~7。
- 目标：`AssessmentEvidence` → 用户可懂估计。50 题后结果页显示点值 + 双侧 90% Wilson 显示用保守范围（z=Φ⁻¹(0.95)≈1.6448536269514722）+ 「基于当前 1,000 词覆盖估计，不做外推」声明。
- 范围：十频段加权点值；unavailable 行为（首测未完成 / 任一频段零有效证据 / 多频段零证据 → 返回 unavailable，显示「完成或重新完成首测后可查看估计」，不显示 0/NaN，零样本频段不按 0 掌握；结果钳制 0–1000）；manual 不影响估计。
- 非目标（重要，反过度设计）：不外推总体词汇量、不输出 CEFR、UI 不得出现「90% 置信区间」字样、范围不驱动任何自动行为、不建设通用统计层/概率画像/估计历史、不为冻结 audit 补测试。
- 测试 seam：estimate 纯函数（strategy 单测，含 Wilson 硬编码期望值 + 浮点 tolerance，测试不得复制生产算法）；E2E §21 场景 5、6 数值与文案断言。
- 验收示例（取自 ticket）：`knownCount=3, testedCount=5, z=1.6448536269514722` → `low≈0.27248317186619286`、`high≈0.857293527980787`，满足 `low ≤ point ≤ high`。
