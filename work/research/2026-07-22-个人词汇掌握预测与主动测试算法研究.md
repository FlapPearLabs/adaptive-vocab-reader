# 个人词汇掌握预测与主动测试算法研究

日期：2026-07-22
状态：研究笔记（非产品规则、非实现规格）
研究问题：单用户浏览器词汇插件只有首次 50 道四选一题、页面“会／不会”标注和每天 5 道可选校准题时，怎样预测**未直接确认**单词的掌握概率，并持续降低“实际会却提示”和“实际不会却隐藏”？

2026-07-22 决策说明：本笔记比较过 Beta-Binomial 与固定难度 Rasch/1PL 候选；现行规格已选择前者的“十频段 Beta-Binomial 后验加权 PAV 单调池化”作为唯一算法。本文中的 Rasch/1PL 仅保留为研究比较与排除理由，不是当前实现指令。

## 先给结论

用户的判断是对的：只按十个词频区间累计分数，不能可靠预测某一个未测单词会不会。它最多是一个冷启动基线。

当前约束下最合适的不是深度知识追踪、BKT、2PL/3PL IRT 或可训练遗忘模型，而是一个分成四层的轻量闭环：

```text
显式单词状态（会／不会） ──硬覆盖──> 页面提示
          ↑
初测、边界校准题、随机审计题 ──> 带不确定度的频段词频先验画像
                                      ↓
                             未确认词的 P(会) 与置信区间
                                      ↓
                    校准题 + “隐藏词”随机审计，修正下一轮预测
```

现行规格采用的名称是：**Beta-Binomial 单调词频画像 + 显式状态覆盖 + 主动审计 + 每日校准轮**。

这里的“贝叶斯”不要求网络、云服务或大模型；它只表示保存概率与不确定度，而不把 50 题的原始分数误当成精确事实。

## 需求拆解：其实是三个不同的问题

| 问题 | 可观测证据 | 正确产物 | 不能用什么替代 |
| --- | --- | --- | --- |
| 当前词是否应提示 | 用户明确会／不会、活跃状态核验或审计结果 | 单词级显式状态 | 词频画像或总分 |
| 未测词大概会不会 | 被随机抽取的测试题与词频难度先验 | `P(会)` 与不确定度 | 把预测直接写成会／不会 |
| 哪些词该再问 | 生词表到期、模型边界与隐藏词抽检 | 每日选题策略 | 只反复抽生词表 |

普通阅读曝光、打开释义和页面出现次数都不在证据表中：它们不应把词变成“会”，也不应用来拟合掌握概率。这与当前产品规则一致。

另一个关键区别是：**页面手动“不会”不是随机样本。**用户更可能在正在阅读、恰好影响理解的词上操作。它对该词是最强证据，但若直接拿来更新全局词频区间，会让模型错误地认为同一频段所有词都更不会。因此，V0.1 应将它用于该词与活跃生词表，不用于更新全局预测画像；只有随机化的初测/审计题才更新全局画像。

## 与问题直接匹配的一手研究

### 1. 词汇表预测与小样本选词

[Robertson, 2021, *Word Discriminations for Vocabulary Inventory Prediction*（RANLP，官方 PDF）](https://aclanthology.org/2021.ranlp-1.134.pdf) 直接研究了：只问有限词后，预测学习者整本词汇表；论文比较了词频基线、2PL IRT 与 CAT，且以约 40 题的快速重新定位作为应用动机。

可用结论：

- 词频是合理、稳健的难度基线，而不是用户真实掌握状态。论文在跨数据集泛化时发现，特定人群拟合的 IRT 难度可能过拟合；高质量词频数据反而更稳健（论文第 5–6 页）。
- CAT 的通用原则是优先询问当前能力估计附近、信息量高的题；在 2PL 情况下可用 Fisher information，选靠近当前能力的题等价于最大熵/不确定性采样（第 3 页）。
- 但该论文中词项“判别度”对小样本泛化、选题和最终预测并未稳定带来收益，作者最后的 CAT 阶段实际去掉了判别度；其原因之一是判别度难以从有限响应中准确估计（第 5–6 页）。这正是否决“单用户本地拟合 2PL/3PL”的证据。
- 四选一答对不是无噪声的“会”。论文的四选一设定明确处理了猜测下限；本项目若将单次答对视为完全确定，会把理论上至少 25% 的纯随机猜测风险忽略掉。

这篇论文的训练与评估数据以日本 L1 学习者为主，不能直接承诺对本项目中文用户也达到相同指标；它证明的是建模与选题原则，而非性能保证。

### 2. IRT 的价值与单用户冷启动边界

[McCarthy 等，2021，*Jump-Starting Item Parameters for Adaptive Language Tests*（EMNLP，官方 PDF）](https://aclanthology.org/2021.emnlp-main.67.pdf) 给出 Rasch/1PL 的基本形式：

```text
P(答对 | 用户 p, 题 i) = sigmoid(能力 θp − 难度 bi)
```

它也说明，能力与题目难度可放在同一 logit 尺度上。对当前项目有用的不是其 BERT 方法，而是它的反例：即使该研究所谓的“小量”冷启动，仍使用约 500 名考生、约 4,000 题库、每题约 6 次曝光。单用户的 50 个回答远不足以学习 10,000 个词各自的难度或判别度。

因此本项目只能把 ECDICT 的 `frq`/`bnc` 秩转换为**固定难度先验**，然后只更新这个用户的能力后验；不得从单个用户重新估计每个词的 `bi` 或 `ai`。

### 3. IRT 与知识追踪不是同一种任务

[Deonovic 等，2018，*Learning meets Assessment: On the relation between Item Response Theory and Bayesian Knowledge Tracing*（arXiv）](https://arxiv.org/abs/1803.05926) 明确区分：IRT 原本对应横截面测评，BKT 原本对应纵向学习记录。

本项目每个词通常只有初测一次、偶尔一次标注和少量复测；这不足以为每个词识别 BKT 的初始掌握、学习、猜测、失误等参数。标准 BKT 也不适合直接表达遗忘。故：

- **不采用**“每词一个 BKT”；
- **不采用** DKT/RNN 等需要大量跨用户顺序日志的模型；
- 若以后积累了明确授权的、大规模、可验证数据，再单独重新研究，而不是提前埋入当前架构。

### 4. 词汇预测的主动抽样

[Ehara 等，2014，*Formalizing Word Sampling for Vocabulary Prediction as Graph-based Active Learning*（EMNLP，官方 PDF）](https://aclanthology.org/D14-1143.pdf) 直接把“从少量查询词预测其余词”的问题定义为词汇预测，并指出词频分段随机抽样隐含“相近频率词掌握相似”的假设。该文在小样本下展示了图式主动抽样优于一些基线。

这支持两个当前结论：

1. 首次 50 题按十个频段分层抽样是合理的**覆盖锚点**，不是随意的总分考试；
2. 更强的图传播需要额外的词相似度图、语料域或多词典数据。它超出 ECDICT 单词级、无额外数据源的 V0.1 范围，**暂不采用**。

### 5. 间隔复测适合“已知不会词”，不适合冷启动预测

[Settles 与 Meeder，2016，*A Trainable Spaced Repetition Model for Language Learning*（ACL，官方 PDF）](https://aclanthology.org/P16-1174.pdf) 的 Half-Life Regression（HLR）用 `p = 2^(-Δ/h)` 表示词在间隔 `Δ` 后仍能回忆的概率，利用同一学习者—词条的多次练习、答对/答错次数和时间间隔训练参数。

该研究证明间隔复习值得做，但其训练使用了 1,290 万条学习者—词条记录。它不能证明一个人几十次记录就能拟合个人遗忘曲线。因此：

- **不采用** Leitner 式阶段复测、HLR、DAS3H 或“预测遗忘率”的个性化拟合：用户已明确每日短测的用途是校准范围与提示边界，不是背单词或间隔复习；
- 每日校准轮中的状态核验只更新被测词；边界校准与隐藏审计按现行 `RULES.md` 更新画像，边界校准词保持未知。

[Zaidi 等，2020，*Adaptive Forgetting Curves for Spaced Repetition Language Learning*（arXiv）](https://arxiv.org/abs/2004.11327) 同样依赖平台级用户、词复杂度和历史交互数据，进一步佐证它是后期有大量数据时的候选，而非当前单用户 V0.1 的算法。

## 候选算法与当前适配性

| 候选 | 数据前提 | 能解决什么 | 不能解决什么 | 当前结论 |
| --- | --- | --- | --- | --- |
| 原始词频区间分数 | 50 个分层答案 | 快速冷启动、覆盖十个频段 | 同频段异质性、置信度、主动校正 | 只作基线/先验 |
| 分层 Beta-Binomial + 单调约束 | 每频段随机题的对错 | 减少每段仅 5 题的偶然波动，输出不确定度 | 领域兴趣、偶然蒙对、词的个体差异 | **推荐 V0.1** |
| 固定难度的贝叶斯 Rasch/1PL | 固定词频难度秩 + 随机题 | 用一个能力后验跨频段平滑预测与选题 | 无法自学每词难度；题目质量差会失效 | **推荐，作为上表的模型表述** |
| 2PL/3PL、每词判别度/猜测参数 | 大量跨用户同题响应与校准题库 | 更精细的题目差异、猜测建模 | 单用户估计不稳；开发和数据成本高 | 不推荐 |
| 图式主动学习 | 词图、多个语料/域权重 | 非词频的相似词外推 | 引入额外数据建模与维护 | 暂不做 |
| BKT/DKT | 每技能大量连续尝试、已知技能映射；DKT还要大量人群数据 | 纵向学习过程 | 当前每词数据过稀，参数不可识别 | 不推荐 |
| HLR/DAS3H | 同人同词的多轮、有时间间隔的练习历史 | 复测排程、遗忘预测 | 冷启动和单用户少量数据 | 不采用；当前没有背词或间隔复习流程 |

## 推荐的最小算法：不是一个总分

### A. 固定题目难度先验

将 ECDICT 的 `frq` 正序、`bnc` 补位后的排名映射为十个频段，并给每个词一个固定难度 `b(w)`：高频词难度低，低频词难度高。这个 `b(w)` 是可重复构建的先验，不因单个用户改变。

首次 50 题维持“每频段五题”的规则。每段随机选词时固定题目版本和干扰项版本；否则用户对的是词、还是题目写得好，无法区分。

### B. 用户能力是一个分布

对随机抽取的测试题，维护用户能力 `θ` 的后验分布，而不是一个确定分数。简化的四选一观测模型可以写为：

```text
P(答对 | θ, w) = c + (1 - c) × sigmoid(θ - b(w))
c = 0.25   # 四选一的猜测下限；实际题目质量须另行验证
```

每答一题，只更新 `θ` 的概率分布；对未确认单词产生 `P(会 | θ, b(w))`。实现时可先用十个频段的 Beta-Binomial 近似，不需要 MCMC：

```text
每个频段：p_b ~ Beta(α, β)
观察到随机抽样题后：p_b | 数据 ~ Beta(α + 答对数, β + 答错或不确定数)
```

再用加权 isotonic/PAV 单调池化，使更高频段的 `P(会)` 不低于更低频段，同时保留每段样本数与区间宽度。这个近似没有声称获得了精确 IRT 能力；它的价值是避免“5 题对 5 题错”被误当成整个频段 0%/100% 的确定结论。

### C. 显式状态永远优先，预测只处理未确认词

```text
用户明确会                 → 会；停止提示；从当前生词表移出
用户明确不会               → 不会；强提示；进入活跃生词表
活跃生词状态核验答对       → 会；移出当前活跃生词表
活跃生词状态核验答错/不确定 → 不会；维持在活跃生词表
普通曝光/查看释义          → 不改变状态或画像
随机审计题的答案           → 更新画像；同时给该词留下可追溯的测试证据
```

四选一初测的单次答对应作为“测试证据”而非与用户手动“我会”完全同质的金标准。若产品仍坚持“初测答对立即变会”，至少要保留来源与次数，并把该词列入未来随机审计候选；否则无法发现一次猜对造成的漏提示。

### D. 展示是可弃权的决策，而非把概率强制变成状态

对未直接确认的词，使用 `P(会)` 和后验区间做三类决策：

| 条件 | 建议动作 | 想控制的错误 |
| --- | --- | --- |
| 明确不会 | 强提示 | 不漏掉已知生词 |
| 未确认、`P(会)` 高且下置信界也高 | 可不提示 | 减少“会却提示” |
| 未确认、`P(会)` 低且上置信界也低 | 轻提示 | 减少“不会却隐藏” |
| 未确认、区间宽/靠近阈值 | 轻提示或进入校准题；不要伪装成会 | 避免 50 题后的过度自信 |

阈值不是先拍一个 70% 就固定；它必须用后续独立审计题校准，并可根据“漏提示”比“误提示”更影响阅读这一产品取舍设定不同成本。

### E. 每天 5–10 题必须分桶

纯粹选择“模型最不确定”的词，能提高模型信息量，却会看不见被模型高置信隐藏的生词；只核验活跃生词表，又无法校正整体预测。现行规则因此把用户选择的 `N=5..30` 题分成三类：`floor(N/5)` 活跃状态核验、`ceil(2N/5)` 未知边界校准，以及剩余隐藏词审计。前者只更新被测词；后两者更新画像。每次出题前应冻结并保存 `预测版本、P(会)、展示决策、抽样桶、题目频段`，答完后再更新。否则会产生“用本题训练后再用本题自证”的数据泄漏。

## 验收：70% 是待验证目标，不能被 50 题宣布达成

“70% 词在前端显示正确，误提示和漏提示各不超过 30%”可以成为 pilot 假设，不能成为算法保证。原因：初测 50 题既太少，又参与了画像训练；拿它回算准确率是训练集自证。

正确验收用**答题前冻结预测**的后续随机审计题，并至少分开报告：

```text
漏提示率 = 审计时预测“不提示”但答错/不确定的比例
误提示率 = 审计时预测“提示”但答对的比例
概率质量 = Brier score 或 log loss + 按 P(会) 分桶的可靠性表
活跃生词状态核验转会率 = 被随机核验后从不会转会的比例
覆盖 = 各频段、各抽样桶的题数与区间宽度
```

审计桶必须包含随机的隐藏词，才有资格宣称了解漏提示率。仅从生词表测验只能验证已经发现的问题，不能验证“模型把不会词藏起来”的问题。

在数据很少时还应报告每个错误率的置信区间，不应只报一个百分比。只有当独立审计样本量足够、两类错误的上界均低于产品阈值，才应认为目标暂时达标。

## 已解决的规则冲突

研究时的 `RULES.md` 曾规定“未知＝轻提示，词频画像只排序未知词的轻提示优先级”。这与“用预测降低实际会却提示、实际不会却隐藏”存在一个真实冲突：如果所有未知词都提示，预测无法决定展示与否，只能改变顺序。

用户已于 2026-07-22 确认采用以下解决方案，并已写入现行 `RULES.md` 与《掌握预测与主动校准规格》：

1. 允许达到概率、下置信界和随机审计三项门槛的“预测会但未确认”词不提示；
2. 初测单次答对立即显示为会，但以待随机审计标记保留猜对风险；审计答对或答错后清理标记。

## 明确不推荐

- 不以一个总分、一次 50 题成绩或单个频段比例直接断定 10,000 个词的状态；
- 不在单用户本地学习每词 IRT 难度/判别度/猜测参数；
- 不用 BKT、DKT、协同过滤、FM 或任何需要大量跨用户训练数据的模型；
- 不把用户网页标记的生词当成全局频率画像的无偏样本；
- 不把普通曝光当成掌握证据；
- 不先做 HLR/DAS3H 等可训练遗忘曲线；
- 不引入 LLM、本地模型、Kaikki、义项/MWE、云服务或新增词典源。

## 后续边界

两个产品决定已解决。下一步不是继续替换算法，而是在可丢弃原型中验证固定难度映射、题目质量、后验近似和真实页面上的误提示／漏提示；原型结果必须回写到新的需求讨论，不能自动改变本笔记、规则或规格。
