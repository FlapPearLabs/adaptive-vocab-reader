# Beta/PAV 词汇策略原型（可丢弃）

这是一个只回答算法问题的终端原型，不是浏览器扩展、词典转换器或生产模块。

它验证：50 道分层初测后的 Beta/PAV 画像；`0.85 / 0.70 / 20 次审计 / Wilson ≤ 30%` 门槛；以及单次答对审计标记的状态迁移。

2026-07-22 的产品确认：每日校准轮允许用户选择 5–30 题，按 `floor(N/5)` 活跃状态核验、`ceil(2N/5)` 边界校准和剩余隐藏审计分配。它不是背单词或间隔复习。候选不足时，空缺只在边界校准与隐藏审计之间按安装种子和测试轮次确定性交替回填；二者也都无候选时才少出题，且不会给活跃状态核验增加名额。

运行（仅 Python 标准库，不下载任何数据）：

```bash
python3 work/prototypes/beta_pav_policy_prototype/tui.py
```

终端菜单可运行三种固定合成学习者、5/10 题日测、规则自检与 PAV 诊断。所有状态只在内存中存在。`policy.py` 是纯算法接口；`tui.py` 是按 `/prototype` Skill 要求制作的可丢弃交互外壳。

重要：PAV 合并 `m` 个频段后，原型使用已确认的 `Beta(m + ΣC, m + ΣU)`；它保留每个频段的均匀先验，且均值与加权 PAV 严格一致。

原型完成后的结论记录在同目录 `RESULTS-2026-07-22.md`。除非用户另行授权，任何代码均不得提升为正式实现。
