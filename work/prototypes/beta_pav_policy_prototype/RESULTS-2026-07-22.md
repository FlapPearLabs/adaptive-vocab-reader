# Beta/PAV 词汇策略原型结果

日期：2026-07-22
状态：已按当前已确认规则重跑的可丢弃原型；不是生产实现。

## 已确认并进入本次重跑的规则

1. 每日校准轮由用户选择 `N` 题，`5 ≤ N ≤ 30`。
2. 配额为：活跃生词状态核验 `floor(N / 5)`、未知边界校准 `ceil(2N / 5)`、隐藏词审计为剩余题数。因此 `N=5` 为 `1/2/2`，`N=10` 为 `2/4/4`，`N=30` 为 `6/12/12`。
3. 活跃状态核验只更新该词；边界校准只更新频段画像且该词保持未知；隐藏词审计更新画像并结算被审计词的状态。
4. PAV 合并 `m` 个频段后使用 `Beta(m + ΣC, m + ΣU)`，保留每个原始频段的均匀先验。
5. 任一候选桶不足时，空缺只在未知边界校准与隐藏词审计间，按安装种子和测试轮次确定的交替顺序回填；活跃状态核验不增加名额。两类候选均耗尽时才少出题。

## 方法与边界

- 固定合成题库：1,000 个词、十个词频段、每段 100 个词，种子为 `prototype-2026-07-22`。
- 每个情境先跑 50 道分层初测，再跑 25 轮每日校准；分别选择 `N=5`、`10`、`30`。
- 三种合成学习者：稳定高掌握、随词频明显下降、高噪声回答。
- 模拟器的“真实掌握”标签只用于比较策略；真实产品不可见，只能用作答前冻结的随机审计答案估计漏提示。
- 无词典下载、无网页、无模型/API、无持久化、无生产代码接入。

## 规则边界验证

| 检查 | 结果 |
| --- | --- |
| Wilson 单侧 90%，`n=20,k=3` | 0.278448，通过 `≤ 0.30` |
| Wilson 单侧 90%，`n=20,k=4` | 0.335284，失败 |
| PAV 违反合并 | 低频段均值高于高频段时会合并 |
| 合并块先验 | 无回答段与一答对段合并后，PAV 均值与 `Beta(3,2)` 均为 0.600 |
| 初测单次答对 → 审计不确定 | 改为不会、加入活跃生词表、清除标记 |
| 手动会／不会 | 不改变频段画像 |
| 边界校准答对 | 更新画像，单词仍为未知 |
| 5 题配额 | `1 / 2 / 2` |
| 10 题配额 | `2 / 4 / 4` |
| 30 题配额 | `6 / 12 / 12` |
| 同种子、轮次与快照 | 选题可重放 |
| 两类审计候选都有时 | 初测单次答对 / 高置信未知词交替抽取 |
| 活跃核验候选不足 | 只由边界校准／隐藏词审计交替回填，不增加活跃核验题 |
| 边界／审计候选均耗尽 | 少出题，不从其他来源硬凑题 |

即使初测每个频段均为 `5/5`，其后验仍只是 `Beta(6,1)`：均值 `0.857`，10% 下界 `0.681`。因此 50 题后不会直接静默未知词；审计数不足 20 也会继续保留轻提示。

## 当前结论

- 已确认的 PAV 公式消除了原先 `0.022–0.037` 的“PAV 均值 / 合并 Beta 均值”差异；该差异现在为零。
- 每日题不再是背词或复习。活跃状态核验只修正已标记单词；全局了解用户范围的证据来自边界校准与隐藏审计。
- 用户选择 5、10 或 30 题时，候选充足则严格采用目标配额；一桶不足时，只会在边界校准和隐藏词审计之间确定性交替回填。
- 当两类回填候选均耗尽时，原型按规则少出题；它不会把空缺塞给活跃生词核验，也不会退回背词式复测比例。

## 候选不足：已确认并验证

受控回填已经确认。稳定高掌握者选择每日 5 题时，25 轮仍抽到 `15 + 26 + 84 = 125` 题：缺少的活跃核验和边界候选由允许的另一类测量题补足，而不是变成复习题。

同时，专门 fixture 已验证两条硬边界：

1. 活跃核验不足、而边界与审计候选都存在时，10 题轮的结果是 `0 / 5 / 5`，没有增加活跃核验题。
2. 边界与审计候选也都耗尽时，5 题轮实际为 0 题，确认“少出题”是最终兜底而非隐式换题。

算法规格的候选不足决策现已闭合。原型不自动变为生产实现；下一步仍需用户明确授权才可整理 tickets 或实施 1,000 词垂直切片。
