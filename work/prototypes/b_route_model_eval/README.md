# 路线 B 本地模型可行性原型（可丢弃）

> **不是生产代码，不接浏览器、词典包、IndexedDB 或用户数据。**

## 要回答的问题

在 LM Studio 的真实本机 OpenAI 兼容接口上，一个小于 4B 的候选模型能否仅凭“目标表达＋最小充分语境”，稳定返回可显示的简中短释义，而不是整句翻译或伪造确定答案？同一输入的第二次请求能否安全命中内存缓存？

这只是路线 B 的早期冒烟验证：它不能证明模型质量达标，更不能替代当前已确认的“先冻结 Codex→Hermes→Reasonix Harness → 第一阶段总计 500 条，前 100 条为其中合同门 → 每 100 条反思并沉淀候选 Skill”验证序列。

## 运行

先在 LM Studio 下载并加载模型、启动本地服务器，再运行：

```bash
python3 work/prototypes/b_route_model_eval/tui.py --model '<LM Studio 已加载模型 ID>'
```

默认只请求 `http://127.0.0.1:1234/v1/chat/completions`。可用 `--base-url` 改为另一个**本机 loopback** 地址；原型使用标准 URL 解析精确限制 `localhost`、`127.0.0.1`、`[::1]`，禁止用户信息、query/fragment 与任何 HTTP 重定向。

快捷键：`n` 跑下一例、`a` 跑全部、`c` 重放当前例（应命中内存缓存）、`s` 输出逐例内存汇总、`r` 清空内存缓存、`q` 退出。

## 判定

每例都会显示原始 JSON、延迟、JSON/合同校验、自动匹配结果和状态。合同校验要求目标表达原样回显、`answer` 与非空短释义／`need_more_context` 与空短释义严格互斥，并限制短释义最多六个字符。自动“通过”只表示输出命中该例预设的可接受短释义之一；其他合同合法输出仍须人工复核。出现整句翻译、错误义项、无效合同、超时或未命中安全缓存，都属于路线 B 的风险证据。
