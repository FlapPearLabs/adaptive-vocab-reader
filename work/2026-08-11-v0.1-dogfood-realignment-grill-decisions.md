## 5a. GRILL 收口合同（2026-08-14 用户确认，不再逐题 Grill）

### 收口 1 —— transition region → personal hint boundary

- transition region 表示用户开始进入「可能需要提示」的难度区域；
- personal hint boundary 应从 transition region **较简单一侧**确定性派生；
- transition region 本身及更困难区域具备 **gray-hint eligibility**；
- explicit known 永远不提示；explicit learning 仍走红色强提示；
- 已测词 Evidence special case 继续优先；
- queryability 不受 boundary 影响。
- 精确窗口端点/rank representative 属实现 bootstrap（DOGFOOD_TUNABLE_PARAMETER），只要求 deterministic。

### 收口 2 —— 最小可信证据与自动提前结束

- calibration 必须**同时观察到 transition region 以及其至少一侧的稳定趋势证据**，才能生成 personal boundary；
- 证据不足或高度矛盾 → fail-safe，继续使用 global T₀；
- 一旦追加样本不再改变已定位的 transition region，并满足上述可信证据合同 → 可提前结束；
- 总题量永远 ≤ 20；
- 最小样本数 / 连续稳定轮数 = DOGFOOD_TUNABLE_PARAMETER；
- 不允许模糊「感觉已经收敛」；实现必须给出**确定性、可测试**规则。

### 收口 3 —— Real reading feedback 持续校准

- manual known/learning 的 query word 若有有效 `effectiveFrequencyRank` → 长期 personalization evidence；
- 单个 manual answer 不得让 boundary 大幅跳变；
- 使用与 calibration 一致的局部趋势 / transition-region 思路重新派生 personal boundary；
- explicit WordState 永远优先，聚合模型不得反写 WordState；
- 无 frequency rank 的 manual state 对该词本身有效，但不参与 rank-boundary calibration；
- 数据不足时保持上一个可信 boundary；从未形成可信 boundary → 回退 T₀。

### 收口 4 —— Persistence

- personal calibration 重启后应继续有效；
- 用户重新完整执行 hint calibration 时，可替换旧 calibration baseline；
- manual reading feedback 继续在此基础上更新；
- 不与 AssessmentEvidence 混存语义；不进入 vocabulary estimate；不伪装成 WordState；
- 实现前先调查当前 schema/storage：能在现有 schema 3 / 兼容存储边界内实现 → 最小方案；真正需要 bump profile schemaVersion → **SCHEMA_CHANGE_REQUIRED STOP 返回用户**；不得为避免 STOP 把 calibration 数据塞进语义不匹配的旧字段。
