# 浏览器词汇学习插件

一个面向已有一定英语基础读者的、本地优先英文网页词汇阅读插件。它以 ECDICT 的一万高频词本地核心包、固定 50 题初测、用户“会／不会”反馈与每日 5–30 题可选校准轮，帮助用户快速继续阅读；它不是背单词或全文翻译产品。

## 当前状态

项目已生成可重复的 1,000 词本地 ECDICT dogfood 数据包，但尚未开始扩展实现；目前没有可安装或可运行的浏览器扩展产物。
