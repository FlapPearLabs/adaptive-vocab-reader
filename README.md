# 浏览器词汇学习插件

一个面向已有一定英语基础读者的、本地优先的个性化网页阅读脚手架。它根据渐进测评、阅读反馈和复测持续更新用户的表达义项掌握模型，只在必要时显示简短中文提示，并在掌握后撤除常规提示。

## 当前状态

项目处于产品与工程规划阶段，尚未开始扩展实现。目前没有可安装或可运行的浏览器扩展产物。
