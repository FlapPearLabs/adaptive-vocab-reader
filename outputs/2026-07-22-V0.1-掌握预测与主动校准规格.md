# V0.1 掌握预测与主动校准规格

日期：2026-07-22
状态：本地规格草案；已综合截至本文件日期的用户确认。产品规则以 [`RULES.md`](../RULES.md) 为唯一规则登记来源。本规格不授予实现、提交、远端写入或发布权限。

## Problem Statement

用户需要一个在英文网页阅读时及时提示真正不会词的本地工具，而不是把所有单词都翻译出来。

只按词频区间的正确率推断用户掌握情况会产生两类无法接受的错误：用户已经会的词被反复提示，以及用户不会的词被隐藏。单纯把 50 题总分或十个词频区间的分数直接映射到约一万词，既没有不确定度，也无法验证是否正在漏掉隐藏的生词。

用户希望通过首次词汇测试、网页中的明确“会／不会”标注，以及每天很短的测试，逐步扩大被可靠识别的词汇范围。不会词必须即时进入生词表并显示提示；会了的词必须移出生词表；对未直接确认的词，系统必须保守地预测、随机审计并量化误差。

## Solution

产品使用“**显式状态优先、保守预测、主动校准、随机审计**”的四层闭环。

```text
ECDICT 固定高频核心包
        ↓
初测 / 校准题 / 隐藏词审计题
        ↓
带不确定度的个人掌握预测画像
        ↓
未确认词的轻提示或高置信不提示
        ↓
用户明确会／不会与每日校准轮的状态核验
        ↓
冻结预测后的独立审计结果，校准下一版画像
```

词典只提供确定的单词、音标、词性与短中文。算法不使用 LLM、上下文解释、Kaikki、义项、MWE、词族传播、云服务或额外词典源。

### 核心原则

1. **显式状态是真实状态。** 每个规范化单词始终为会、不会或未知之一；预测不能把未知写成会／不会。
2. **预测仅服务未确认词。** 画像只输出该词 `P(会)` 与不确定度，用于轻提示、静默展示和下一题选择。
3. **手动标记不污染总体画像。** 网页上的“不会”高度偏向正在阅读、恰好造成困难的词；它是该词的强证据，不是随机样本，不能直接外推到同频词。
4. **没有审计就没有漏提示指标。** 必须抽测当前被隐藏的词，才能知道“不会却未提示”是否下降。
5. **高置信是保守展示门槛，不是新的用户状态。** 不满足任何高置信条件时，未确认词保留轻提示。

## User Stories

1. 作为英语网页读者，我想先完成一组覆盖不同词频段的短测试，以便插件快速形成初始而非武断的掌握画像。
2. 作为读者，我想答对的测试词立即不再提示，以便已会词不会打断阅读。
3. 作为读者，我想答错或选择不确定的测试词立刻进入活跃生词表，以便随后阅读中得到中文提示。
4. 作为读者，我想在网页上选中一个词并标记不会，以便无需等待下一轮测试就立即获得强提示。
5. 作为读者，我想把一个词标记为会，以便立即撤除提示并从当前活跃生词表移出。
6. 作为读者，我想让没有明确状态的词只在系统证据不足时轻提示，以便不必面对整页翻译。
7. 作为读者，我想让系统只在足够可靠时静默隐藏预测会的未知词，以便减少误提示而不随意漏掉生词。
8. 作为读者，我想每天可选完成 5 道校准题，以便更新词汇范围与提示边界，而不被测试打断阅读或进入背词计划。
9. 作为读者，我想让少量题目检查系统隐藏的词，以便系统能发现自己把不会词藏起来的错误。
10. 作为读者，我想知道系统的误提示率、漏提示率和校准程度，而不是只看到一个不可信的“词汇量分数”。
11. 作为读者，我想让单次四选一答对的词仍有机会被低频核验，以便偶然猜对不会永久造成漏提示。
12. 作为读者，我想让所有状态与测试数据只保存在本机，不保存网页正文、URL、句子或浏览历史。
13. 作为读者，我想在刷新页面后仍保留会、不会、活跃生词表和已完成的测试状态。

## Implementation Decisions

### 1. 领域对象与证据边界

每个词典主词条以规范化单词为键，维护下列彼此分离的信息：

- **个人词汇状态**：会、不会或未知；这是页面提示的最高优先级输入。
- **状态证据来源**：初测答对、初测答错／不确定、用户手动会／不会、活跃生词状态核验答对／答错／不确定、随机审计答对／答错。
- **预测画像**：只由随机初测、校准题和隐藏词审计题的结果更新；保存版本、词频难度先验、用户能力后验、每个频段样本量与不确定度。
- **审计标记**：只用于初测单次答对词和高置信不提示的未知词；它不是用户可见的第四种状态。
- **活跃生词表条目**：不会词的当前状态证据与最近一次状态核验结果；它没有复习阶段、到期时间或学习排程。

普通曝光、页面出现次数、悬停、查看释义、滚动、停留时长和未操作都不得改变个人词汇状态或训练预测画像。

### 2. 词频难度与掌握预测

ECDICT 的 `frq` 正序、缺失时的 `bnc` 补位确定约一万词的稳定排名。构建阶段将排名映射为十个频段和固定难度先验：高频词难度较低，低频词难度较高。该难度是数据包属性，不会被单个用户重写。

预测画像的唯一算法是**十频段 Beta-Binomial 后验加权单调池化**。这是一个低样本、单词级的预测器，不声称是已校准的 Rasch／IRT 测验：

1. 每个频段先使用均匀先验 `Beta(1, 1)`。随机测试中答对计为 `C`，答错或不确定计为 `U`，该频段原始后验为 `Beta(1 + C, 1 + U)`。
2. 按从高频到低频的顺序，对十个频段的后验均值做加权 PAV 单调池化；权重为该段 `C + U + 2`。出现“低频段预测会率高于高频段”的相邻违反时，合并为一个区间块。
3. 一个 PAV 合并块若包含 `m` 个原始频段，则后验为 `Beta(m + ΣC, m + ΣU)`。它保留每个原始频段各一个 `Beta(1,1)` 先验，故块后验均值与权重 `C + U + 2` 的 PAV 均值严格一致；块内所有未确认词共享该后验，单侧 90% 后验下界是该 Beta 分布的 10% 分位数。
4. 每道用于画像的题在作答前冻结预测版本与输出，作答后才更新画像，禁止用本题更新后的模型回算本题正确性。

初测四选一答对仍按产品规则立即产生会状态，但其统计观测存在猜对风险；该风险由单次答对审计标记与后续随机审计处理，不在单用户数据上伪造每题的猜测参数。未确认词只获得 `P(会)`、单侧 90% 后验下界与模型版本；它仍保持未知状态。

当前版本不使用 1PL/Rasch、2PL/3PL IRT、BKT、深度知识追踪、协同过滤、图传播、个体遗忘曲线或可训练间隔复习模型。它们需要当前项目没有的题目校准、跨用户或同词多轮数据。

### 3. 策略模块与测试 seam

所有算法复杂度必须收敛在一个深模块“词汇展示与测试策略”中。其 Interface 接收固定词典快照、个人词汇状态、随机测试证据、审计记录、测试轮次和当前页面命中词；只输出三类结果：页面展示决策、下一轮题目计划和原子状态变更。

页面扫描、存储适配和 UI 只能消费该模块的输出，不能自行重算 `P(会)`、高置信门槛、抽样顺序或审计清理。这样调用方不需要了解后验、PAV、稳定哈希或 Wilson 上界；测试也只需跨这一条 seam 验证用户可见行为。

### 4. 初测

首次测试固定 50 题，十个词频段各五题。每个频段中的候选由固定输入快照内的合格词条组成，以本机安装随机种子做可重现的均匀抽样；题目、正确选项与干扰项版本在开始测试时冻结。

每题规则如下：

- 答对：立即将该词状态设为会，当前页面不提示；同时创建“单次答对、待随机审计”标记。
- 答错或不确定：立即将该词状态设为不会，加入活跃生词表。
- 测试题为分层随机样本，因此结果可更新预测画像。

### 5. 页面标注与生词表

用户在任何已命中词典的网页词上操作时：

- 标记不会：状态立即改为不会、进入活跃生词表、当前出现立即强提示；移除该词已有的审计标记。
- 标记会：状态立即改为会、移出活跃生词表、撤除当前提示；移除该词已有的审计标记。
- 页面手动动作只更新该词和其活跃生词表；不得更新用户的总体预测画像。

不会词的同页首次显示下划线与行内短中文，同页重复仅保留下划线与悬停查看。会词不提示。

### 6. 高置信不提示

未知词默认轻提示。只有同时满足以下所有条件，未知词才允许不提示：

1. 当前状态仍为未知，且不存在用户明确不会或失败审计；
2. 当前画像给出的 `P(会)` 后验均值 `≥ 0.85`；
3. 该词 `P(会)` 的单侧 90% 后验下界 `≥ 0.70`；
4. 当前画像版本已经完成至少 20 道随机隐藏词审计；
5. 该版本的随机隐藏词审计中，漏提示率的单侧 90% Wilson 上置信界 `≤ 30%`。

任一条件失效时立即回退为轻提示。高置信不提示只是不打扰阅读的展示决策；该词继续属于未知，必须仍可被随机审计和用户手动标记不会。

漏提示率的 Wilson 上界采用固定的单侧 90% 常数 `z = 1.2815515655`。若审计总数为 `n`、漏提示数为 `k`，则使用标准 Wilson 上界；`n < 20` 自动视为未达到高置信门槛。这样“20 道审计”和“≤30%”在所有实现中有唯一口径。

### 7. 每日校准轮与确定性随机抽样

每日校准轮为用户可选的 `N` 题，其中 `5 ≤ N ≤ 30`。它的目的仅是更新对用户词汇范围、提示边界和单词状态的认识，不是帮助用户背诵、安排间隔复习或拟合遗忘曲线。

候选只来自三类测量对象：

- **活跃生词状态核验**：从当前状态为不会的词中抽取，用来确认该词是否仍应强提示；它不是按到期时间安排的复习题。
- **未知边界校准**：从未确认、预测接近展示门槛的词频段中分层随机抽取，用来缩小画像在关键边界附近的不确定度。它的答案只更新画像；该词保持未知，不创建审计标记。
- **隐藏词审计**：从当前不提示的单次答对词与高置信不提示未知词中分层随机抽取，用来直接测量漏提示。

题量目标为：活跃生词状态核验 `floor(N / 5)`，未知边界校准 `ceil(2N / 5)`，隐藏词审计 `N - floor(N / 5) - ceil(2N / 5)`。因此 `N=5` 为 `1/2/2`，`N=30` 为 `6/12/12`；隐藏词审计在所有允许题量中至少有两题。候选充足时必须精确采用该配额。活跃状态核验只更新被测词，不进入总体画像；边界校准与隐藏词审计更新画像。某个候选桶不足时，空缺只在未知边界校准与隐藏词审计之间按安装种子和测试轮次确定的交替顺序回填；活跃状态核验不获得额外名额。两类候选也都耗尽时才少出题。旧的“生词复测→隐藏词审计→边界校准”回填规则不能恢复。

所有“随机”都采用本机安装时生成的私有随机种子。每类候选先选择当前该类覆盖率最低的词频段，再在该段候选中按 `安装种子 + 测试轮次 + 规范化单词` 的稳定哈希排序选取。这样对用户保持不可预测，同时可以从本地记录复现某次选择；不需要联网，也不保存网页信息。

活跃状态核验、边界校准与隐藏词审计的题目在作答前记录选题桶、词频段、预测版本、`P(会)`、展示决策和审计来源。隐藏词审计是性能衡量的随机样本；页面手动标记和活跃状态核验不进入总体画像。

### 8. 单次答对审计标记的生命周期

初测答对产生的待审计标记只包含规范化单词、来源、状态版本、创建时间和待审计标志；不得保存阅读上下文。

- 候选池：所有仍为会且来源为单次初测答对的词，加上所有当前高置信不提示的未知词。
- 审计选择：隐藏词审计桶在两类候选之间交替抽取；某类为空时由另一类补位。各频段按覆盖不足优先，段内按稳定哈希均匀抽取。
- 审计答对：状态保持或改为会；清除该词的待审计标记；记录一次已验证审计事件。
- 审计答错或不确定：状态立即改为不会、加入活跃生词表；清除待审计标记；记录一次失败审计事件。
- 用户手动会／不会、词典包更新移除该词、或状态版本改变：立即清除待审计标记，防止陈旧标记再次出题。
- 审计标记在结算后不保留为队列记录；仅保留最小的状态证据与最近审计结果。它不需要用户手动清理。

### 9. 活跃生词状态核验

不会词进入活跃生词表，不产生复习阶段、下一次到期时间或学习计划。用户自愿开启每日校准轮时，可以随机抽取其中的词做状态核验：答对转为会并移出活跃生词表；答错或不确定维持不会。它只更新被测词，不进入总体画像；该行为是对已有状态的重新测量，不是练习排程。

转会词不进入自动遗忘模型，也不自动变回不会。它可作为隐藏词审计候选被极低频抽中，但这属于算法质量审计，不是用户可见的背词负担。

### 10. 隐私与本地边界

所有状态、预测、测试、审计和随机种子仅保存在本机。不得保存 URL、域名、页面标题、完整网页、句子、上下文、浏览历史、模型输出或任何云端同步数据。

## Testing Decisions

最高测试 seam 是“词汇展示与测试策略”模块的 Interface：给定固定词典快照、单词状态、预测画像、审计记录、测试轮次和当前页面词，输出页面展示决策、下一轮题目计划和状态变更。测试只断言这一 Interface 的外部行为，不穿透后验实现或存储结构。

### 行为验收

1. 初测在每个词频段精确选择五题；同一安装种子与输入快照产生相同题目与选项版本。
2. 初测答对立即不提示、状态为会，并存在待审计标记；答错／不确定立即强提示并加入活跃生词表。
3. 网页手动不会立即强提示、加入活跃生词表且不改变预测画像；网页手动会立即撤除提示、移出活跃生词表且不改变预测画像。
4. 普通曝光、悬停、查看释义和滚动不会改变状态、预测画像或活跃生词表。
5. 未知词只有满足全部高置信门槛时才不提示；任一预测、区间、审计样本量或漏提示上界条件不满足时必须轻提示。
6. 每日校准轮允许 `N=5..30`；候选充足时精确生成 `floor(N / 5)` 道活跃状态核验、`ceil(2N / 5)` 道未知边界校准和剩余的隐藏词审计，`N=5` 为 `1/2/2`，`N=30` 为 `6/12/12`。任一桶不足时，只能由未知边界校准与隐藏词审计按确定性交替顺序回填，活跃状态核验不得获得额外名额；两者也无候选时才可少出题。不得恢复旧的复测比例或间隔复习规则。
7. 隐藏词审计在单次初测答对词与高置信不提示未知词之间交替；同一测试轮次、种子和候选快照可重现选择，状态变更后不会再次选择陈旧候选。
8. 单次答对词审计答对后清理标记；审计答错／不确定后变为不会、进入活跃生词表并清理标记。
9. 高置信未知词审计答对后变为会；审计答错／不确定后变为不会；两种结果都停止该次审计标记。
10. 刷新与重启后，状态、活跃生词表、预测版本、审计待办和测试轮次保持；不包含 URL、正文或句子。
11. 在静态正文、SPA 动态插入和无限滚动 fixture 中，只有正文命中的词进入展示策略；代码、表单、导航、评论与扩展节点不进入。
12. 给定相同的随机证据，Beta 后验、PAV 合并块、后验均值与 10% 分位数保持确定性；低频段原始均值超过相邻高频段时必须合并，不能保留违反词频单调性的输出。若合并块含 `m` 个原始频段，其后验必须为 `Beta(m + ΣC, m + ΣU)`，而非丢弃其中 `m-1` 个先验。
13. `n = 19` 的隐藏词审计永远不允许高置信不提示；`n = 20、k = 3` 的单侧 90% Wilson 上界符合 `≤ 30%`，`n = 20、k = 4` 不符合，确保门槛没有歧义。

### 算法验收与报告

算法质量只用作答前已经冻结展示决策的随机隐藏词审计计算。每次报告至少分开给出：

- 漏提示率：审计前不提示、审计答错或不确定的比例；
- 误提示率：随机校准样本中提示、答对的比例；
- 各频段和各选题桶的样本量；
- `P(会)` 分桶后的实际答对率，以及 Brier score 或 log loss；
- 上述错误率的单侧置信上界。

“整体正确率 70%”只能是 pilot 假设，不能以已参与训练的首次 50 题计算。只有独立随机审计达到足够样本量，且漏提示率、误提示率及其上界符合用户确认阈值，才可说当前画像在该用户上暂时达标。

## Out of Scope

- Kaikki、OEWN、COW、多源词典、逐条清洗、LLM、本地模型、云模型、全文翻译、上下文解释；
- 义项、短语、MWE、俚语、派生词、词族状态传播；
- 2PL/3PL IRT、BKT、DKT、协同过滤、图式主动学习、背单词计划、间隔复习、可训练遗忘曲线；
- PDF、OCR、字幕、电子书、跨域 iframe、云同步、公开发布；
- 从网页行为、URL、页面文本、滚动或查看释义推断掌握状态；
- 在无独立随机审计样本时宣称模型准确率达到目标。

## Further Notes

本规格采用研究中得到的限制，而不是照搬论文的完整系统：个人词汇难度模型与主动选题优于单纯频率阈值，但现有研究常使用额外训练语料、心理语言学特征或大规模参与者数据。V0.1 只保留在当前数据规模下仍可解释、可本地运行的部分。

关键研究证据见《个人词汇掌握预测与主动测试算法研究》：它说明单一频率阈值不足、2PL/3PL 与知识追踪的样本前提不成立，以及为什么隐藏词审计不可省略。

实现前仍需用可丢弃原型确认：四选一干扰项质量、页面轻提示密度，以及真实浏览器中的性能和隐私边界。原型不自动转为生产实现。
