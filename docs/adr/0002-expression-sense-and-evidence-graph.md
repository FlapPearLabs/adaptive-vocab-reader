# ADR-0002：以表达义项承载掌握状态，以关系图提供候选与证据

产品面向已有较多基础词汇、但会被少量陌生表达打断的读者。对这类用户，把状态只挂在字符串、lemma 或整个词族上都会产生明显错误：认识 `run` 的常见运动义，不等于认识 `run a company`、`rerun`、`run into` 或习语；反过来，所有屈折形式都逐个提示又会造成不必要打断。

V0.1 因此以“表达义项”作为可独立判断掌握情况的身份单位。屈折、派生、复合、粗义项和 MWE 关系保存在候选与证据图中，用于表达识别、个性化模型特征、来源追溯和解释，但关系本身不直接把另一个表达写成用户明确掌握。

具体含义是：

- 高置信属于同一表达义项的屈折形式可以共享规范化证据，但精确身份规则须由词典 PoC 和 fixture 冻结；
- 透明派生只能影响概率或提示强度，不能凭构词关系生成明确“已会”事实；
- MWE、习语、词汇化搭配、复合词和不同粗义项保持独立，组成词已知不能使其自动隐藏；
- 用户“我会／不会”属于直接反馈，优先于关系推断和群体先验；其跨页面、跨实例传播范围另由产品规则确认；
- 语境或表达身份不可靠时，系统保留候选或轻提示，不通过扩大状态传播来追求更少提示。

被否决的替代方案包括：整个 lemma 或词族共享状态；由人工表达图和固定阈值直接决定掌握真值；完全不利用任何词形关系而让常见屈折重复打断。当前选择把语言关系的复杂性留在后台，同时保留用户前台只有“会／不会”等简单动作。

代价是词典清洗必须产出稳定、可追溯的表达义项身份，运行时还要分别处理表达成立、语境义项、个人未知概率和提示成本。相关精确算法、阈值和“我会了”的跨实例作用域不是本 ADR 的决定，必须通过 `/grill-with-docs`、词典 PoC 和 dogfood 单独冻结。
