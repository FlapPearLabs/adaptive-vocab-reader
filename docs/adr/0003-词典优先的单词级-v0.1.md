# ADR-0003：词典优先的单词级 V0.1

> 本决定中「以规范化单词承载状态、词形表不传播状态」的部分已被 [ADR-0004：词汇键与测试证据分离](./0004-词汇键与测试证据分离.md) 取代；词典优先、拒绝 Kaikki/LLM/模型路线的部分仍然有效。以下为历史正文，保留原样。

V0.1 选择固定 ECDICT 输入筛出的约一万高频单词核心包，并以规范化单词承载会／不会／未知状态；词形表只用于命中词典，不传播状态。我们刻意不实现 Kaikki 义项/MWE 图、LLM 清洗或本地模型，因为当前目标是先交付“网页扫描→本地快查→提示→直接反馈→本地保留”的可用闭环；这些能力若在真实 dogfood 中成为瓶颈，再以新的证据和决策单独引入。
