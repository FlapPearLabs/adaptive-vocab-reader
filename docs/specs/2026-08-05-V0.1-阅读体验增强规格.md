## 2. 用户闭环

```text
阅读英文网页（unknown 词浅灰虚线 + 悬停显示 词形/音标/词性/释义）
→ 拖选不认识的词 → 「加入生词本」浮动按钮 → WordState=learning（不改证据/估计）
→ 该词同页立即升级为强提示（行内中文），后续仅下划线
→ 打开 popup「生词本」页签查看 learning 词列表（音标/词性/释义）
→ 一键「已掌握」→ WordState=known，移出列表，页面不再提示
→ 刷新/重启持久化不变（无新增持久化字段）
```

## 3. Goals

1. unknown 轻提示悬停展示完整学习信息（词形 + 音标 + 词性 + 释义），减少“看不到翻译”的误判。
2. 提供选区级手动入口「加入生词本」，把任意命中词快速标为不会。
3. popup 提供「生词本」页签，让「活跃生词表」从规则变为可见、可核验的清单。

## 4. Non-goals

- 词典扩容（1,000 → 10,000）、派生词/词族/义项/MWE/俚语传播。
- SRS、遗忘曲线、到期队列、复习计划、通知、闹钟、调度器、自动 popup。
- 上下文解释、全文翻译、模型（Ollama/LM Studio/云）、Kaikki/OEWN。
- 选区翻译、选区整段释义、选区文本任何形式的持久化或记录。
- 日志、遥测、上报、dashboard；保存 URL/标题/正文/句子/选区文本。
- 修改 schemaVersion、迁移规则、WordState/AssessmentEvidence 双真相源语义。
- audit 扩建、审计入口复活、隐藏词审计、Pool B。
- 生词本列表的分页、搜索、排序选项、批量操作（仅支持一键「已掌握」）。

## 5. 范围（逐项语义，来自 RULES.md「阅读体验增强」）

### 5.1 轻提示 tooltip 升级

- unknown（`.avr-light`）词悬停显示四行：`词形（surfaceForm，保留原文大小写）`、`音标`、`词性`、`简短中文释义`。
- 音标/词性/释义统一取自 `wordKey` 对应 core 词条（`wordKey === entryKey`；屈折词形如 `went` → 取 `go` 的条目）。
- 下划线样式维持轻提示（浅灰虚线）；learning 强提示（`.avr-strong*`）的行内中文行为不变。

### 5.2 选区加词

- 触发：页面任意位置拖选文本（`mouseup` 后检查选区）。
- 解析：选区文本归一化（trim、去首尾标点、小写）后**整体**作为一词解析——命中 core 主词条或 forms 词形映射 → 唯一得到 `wordKey`。
- 弹出：选区旁浮动按钮「加入生词本」。
- 点击：写入该 `wordKey` 的 `WordState=learning`（source=manual；不写 `AssessmentEvidence`、不改估计）；立即增量更新该词页面提示为强提示。
- 抑制：选区含空白/多词、部分词形整体未命中、未收录词、纯空白、纯数字 → 静默不弹；该 `wordKey` 已 learning 或 known → 不弹；选区消失/点击其他区域 → 关闭浮条。
- 隐私：选区文本仅瞬时本地用于解析；不持久化、不记录、不进快照。

### 5.3 popup 生词本页签

- 数据源：只读 `WordState`；筛选 `status=learning` 且 key 为当前词包内合法 `wordKey`；按 `updatedAt` 降序。
- 展示：wordKey + 音标 + 词性 + 释义（词包内合法 key 才有元数据）。
- 一键「已掌握」：对该 `wordKey` 写入 `WordState=known`（source=manual；不写证据、不改估计）并移出列表。
- 排除规则：schema 3 迁移中无法映射到 core/forms 的旧 key 在存储中保守保留，但**不进入生词本列表**（无元数据可展示；不删除该存储键）。
- 不改首测/每日/估计入口；不读 `AssessmentEvidence`。

## 6. 数据、隐私与失败行为

| 场景 | 行为 |
|---|---|
| 选区无法唯一解析为 wordKey | 静默不弹，无任何写入 |
| 选区文本 | 仅瞬时内存用于解析；不持久化、不记录、不进快照 |
| tooltip 内容 | 仅运行时 DOM 展示；不落盘、不进快照 |
| 生词本遇到无法映射旧 key | 列表排除该 key；存储键保留不删 |
| 重复加词 | 已 learning/known 不重复弹出；已 learning 词仍显示在生词本 |
| popup 打开时无词典数据 | 生词本页签显示空态或加载失败，不写任何状态 |
| 「已掌握」写入被 worker 拒绝 | 刷新真实状态，不本地臆断 |

## 8. 反过度设计门禁

1. 选区加词复用现有 manual 状态写入路径（annotator 已有 click→会/不会菜单；本票仅增加选区→浮条入口与同一 `STATE_CHANGE` 消息），不建新消息协议或服务层。
2. 生词本页签是 popup 内一个只读视图 + 复用 `STATE_CHANGE`，不建独立页面/路由/状态管理。
3. tooltip 升级只扩展 span 的 `data-*` 属性与 tooltip 渲染，不建组件框架。
4. 不引入 repository/service/controller、事件总线、mock-only seam、调度器、迁移框架。
5. 每项 ticket 对应用户可见行为（悬停信息更全 / 能加词 / 能看生词本），回答“用户现在多得到了什么”。

## 9. 风险与延期项

| 风险 | 处理 |
|---|---|
| 选区解析的“整体命中”语义与用户直觉（选区含标点/混合大小写）不符 | 归一化规则写入 Spec 与测试；E2E 覆盖典型用例 |
| GitHub 等 SPA 页面选区事件与页面自身行为冲突 | 浮条仅瞬时 DOM、pointer-events 隔离；E2E 覆盖真实页面 |
| 生词本列表为空 / 全为无法映射旧 key | 空态文案 + 排除规则；不伪造数据 |
| 与既有 annotator 点击菜单并存的双入口 | 选区浮条与点击菜单互斥（浮条出现时点击菜单不触发）；E2E 负向断言 |
