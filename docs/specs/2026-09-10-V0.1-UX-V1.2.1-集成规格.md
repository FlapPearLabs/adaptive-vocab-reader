## 3. 三态标注约定（强制）

本规格所有规范性条目必须落入且仅落入下列三种状态之一。混用或省略视为规格缺陷。

| 标记 | 含义 |
|---|---|
| **`CURRENT_IMPLEMENTATION_FACT`** | 2026-09-09 fresh 验证（或本阶段源码/E2E 复核）**已确认存在于 main** 的行为。任何人不得把它当作待实现工作。 |
| **`NEW_TARGET_BEHAVIOR`** | 外部 UX V1.2.1 引入、仓库当前**不存在**或与当前行为**实质不同**、且不与仓库权威冲突的目标行为。这是唯一允许进入实施 backlog 的类别。 |
| **`HISTORICAL_SUPERSEDED`** | 历史上被提出但已被 `RULES.md` / 本规格 / 外部 UX V1.2.1 自身纠正取代的行为。仅作存史，**不得重新实现**。 |

以下缩写在矩阵中使用：`FACT` / `NEW` / `SUPERSEDED`。

## 4. 保留的仓库契约（外部 UX 不得覆盖）

以下契约由仓库权威定义，外部 UX 文档已显式声明服从（`UX_SPEC_V1.2.1` §1.2）。

| 契约 | 位置 | 保留要点 |
|---|---|---|
| `wordKey` | `CONTEXT.md` / ADR-0004 / `RULES.md`「词汇键」 | ECDICT 主词条小写形式；core 主词条优先；屈折词形映射共享同一键。**不由 UX 引入词元/词族理论。** |
| `DictEntry` | `extension/src/shared/types.ts:19` | 字段名固定为 `phonetic` / `pos` / `translation` / `effectiveFrequencyRank?`。**禁止引入 `ipa`、`zh`、`detailZh`、`nuance` 等别名或旧字段。** |
| `WordState` | `types.ts:40` | `status` + `source` + `updatedAt`；只由最后一次显式动作写入。 |
| `AssessmentEvidence` | `RULES.md`「词汇状态与测试证据」 | 估计 / 是否已测 / 最久未测的唯一读取源；manual 标记不写入。 |
| `QuizQuestion` | `types.ts:79` | `word` / `band` / `options[4]` / `correctOptionIndex` / `unsureIndex`（恒为 4，独立于四个中文选项）。 |
| `QuizAnswer` | `types.ts:70` | 判别联合：`{kind:'option', optionIndex}` \| `{kind:'unsure'}`。 |
| 隐私边界 | `RULES.md`「存储与迁移」/ 08-06 规格 §11 | 快照不得含 URL、域名、页面标题、正文、句子、浏览历史。 |
| 估计语义 | `RULES.md`「词汇量估计」 | 单点 + 双侧 90% Wilson 保守范围，钳制 0–词包大小；不输出 CEFR 等外推量级。 |

**外部文档自身的服从声明**（`UX_SPEC_V1.2.1` §1.2.2 / §1.2.3）：不指定 schema 迁移、不发明新持久化模型、不把 `ipa`/`zh` 定义为生产字段名。本规格采纳该声明并提升为仓库约束。

## 6. CURRENT IMPLEMENTATION FACTS（2026-09-10 复核）

以下为**已存在且已验证**的行为。任何后续 ticket 若把它们写成「待实现」，视为规格缺陷。

1. **透明查询 span**：所有 query-eligible 词都包 `avr-word`；decision 只决定视觉类。known 词刷新后仍为 `className === 'avr-word'` 的可查询透明 span（E2E `e2e-verify.cjs:472-473`），**推翻** `RULES.md` 旧述「known 词被还原为纯文本且无交互载体」。
2. **稀疏灰线**：`hintDisplayDecision(effectiveFrequencyRank, status, threshold)` + bootstrap 阈值 `S[⌊n/2⌋]`；实测 light/100 词 ≈ 4.55。
3. **未收录响应**：`当前词典未收录`，click 不弹菜单、零持久化写入（E2E AC-10）。
4. **包外词**：可写 `WordState=learning`、可进入生词本并展示完整元数据、**不污染 `AssessmentEvidence`**（E2E `e2e-verify.cjs:1234-1241`，样本词 `serendipity`）。
5. **Tooltip 几何**：上方优先 / 下方翻转 / 不侵入 sticky / 不越视口 / 滚动后正确，均已 fresh 验证。
6. **行内释义首现契约**：`showInlineTranslation = isLearning && occurrenceCount === 1`，**不是用户设置**。
7. **真实鼠标拖选**：`mouseup` + `selectionchange` 真实时间线，E2E 覆盖真实 click 序列。
8. **无任何设置持久化**：`storage.ts` 无 settings 键；无 Settings 页签。
9. **无 `METADATA_RESOLUTION_FAILURE` 概念、无 `释义暂不可用` 文案**：全库零命中。
10. **Popup 为两页签**（测评 / 生词本），宽度 `380px`，无搜索筛选、无本页词表。
11. **点击层为极简操作菜单**（`会 / 不会` 两按钮，锚定于目标词左下），无词头/音标/词性/释义展示，无 Esc 关闭。

## 8. 明确保留的外部 UX 权威纠正（不得被后续实现回退）

1. **测评契约**：首测/校准 UI 必须绑定仓库 `QuizQuestion`（目标词 + 仓库候选项 + 独立「不确定」+ `current/total`）。**不得恢复二元 `Need Gloss / I Know This` 模型。**
2. **流程不合并**：首测与每日校准是两个独立领域流程，不得合并为单一 UX/领域契约。
3. **元数据失败正交**：`METADATA_RESOLUTION_FAILURE` 与词汇学习状态正交；不得改 `WordState`、不得伪装成 known/learning/unknown、不得仅因元数据失败而改写词汇状态样式。
4. **词身份与状态权威**：沿用 `wordKey` 与显式状态优先级；**不得为迎合旧稿或旧 mockup 重新引入 `detailZh` / `nuance` / `ipa` / `zh` 字段。**
