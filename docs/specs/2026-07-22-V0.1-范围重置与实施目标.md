# V0.1 范围重置与实施目标

日期：2026-07-22
状态：已确认的方向摘要；产品规则以根目录 `RULES.md` 第 0 节为准。

## 最终目标

交付一个供单用户本地 dogfood 的 Chrome 网页词汇阅读插件。它不是网页翻译器，也不是词典编纂、LLM 清洗或本地模型项目。

用户在普通英文网页阅读时，插件从内置本地词典快速查得单词的音标、词性与简短中文；用户通过首次词汇测试、阅读中的“会／不会”和每日 5–30 题可选校准轮，让提示逐渐贴近自己的真实词汇范围。校准轮不是背单词或复习计划。

```text
ECDICT 高频核心包
→ 网页正文英文单词
→ 本地内存查询
→ 强提示 / 轻提示 / 不提示
→ 会／不会直接反馈
→ 本地保存与每日校准轮
```

## V0.1 必须具备

1. 固定 ECDICT 快照经确定性筛选产生约 10,000 个高频单词：`frq` 正序主排，缺失以 `bnc` 正序补位；运行时只含单词、音标、词性、简短中文和必要词形映射。
2. 普通 HTTPS 英文网页正文的增量扫描；词典在内容脚本内存中快查，静态词典不经数据库、Service Worker 或模型热路径查询。
3. 固定 50 题初测：十个频率区间各五题，题型为英文单词对应四选一中文释义或“不确定”。
4. 单词级 `会／不会／未知` 状态；直接作答和用户动作优先，普通曝光不改变状态。未确认词的掌握预测与真实状态分离。
5. 三档提示：会不提示；不会首次行内简短中文、重复下划线；未知默认轻提示，只有满足高置信门槛的预测会词可以不提示，且必须进入随机隐藏词审计。
6. 用户可选每日进行 5–30 题校准轮，按 `floor(N / 5) / ceil(2N / 5) / 剩余题数` 在活跃生词状态核验、未知边界校准与隐藏词审计间分配；候选不足时只在后两者间确定性交替回填，两者均不足才少出题。它不安排背诵、复习或遗忘训练，阅读不被强制打断。
7. 用户状态仅保存在本机，刷新后仍有效。

## 明确不做

- Kaikki、OEWN、COW、多源词典对齐和逐条语义清洗。
- Reasonix、DeepSeek 或其它 LLM 的词典补缺、批量清洗与运行时参与。
- Ollama、LM Studio、云模型、自动／手动上下文解释、全文翻译与模型缓存。
- 义项、MWE、俚语、派生词、词族传播、2PL/3PL 等复杂概率测验模型、证据账本和复杂容量治理。
- PDF、字幕、OCR、电子书、跨域 iframe、公开上架或云同步。

## 实施顺序与验收

先制作约 1,000 词的可丢弃垂直切片，且只能以真实浏览器完成以下闭环验收：

1. 打开普通英文网页能扫描正文而不处理代码、表单和导航。
2. 命中单词可从内置本地词典立即显示中文提示。
3. 点击会／不会后，当前页面显示立即改变。
4. 刷新后状态仍保留。

通过后用**同一**转换脚本和相同交互扩展至约 10,000 词。任何新增数据源、模型、复杂语言单元或架构层，都必须先由真实 dogfood 证明当前闭环无法满足需求，再重新完成决策。

## 已知边界

- ECDICT 没有官方的一万高频词清单；排序、过滤和输入版本必须由本项目固定并可重复。
- ECDICT 仓库是 MIT，但其释义的逐条再分发权利链尚未验证；当前只作为个人 dogfood 候选，公开发布前必须单独审查。
- 词典快查不是性能瓶颈；首个原型需要实测的是正文扫描、DOM 修改和提示密度。
