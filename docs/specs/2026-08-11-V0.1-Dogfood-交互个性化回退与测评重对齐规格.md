## 2. BACKGROUND_AND_DOGFOOD_EVIDENCE

### 2.1 真实 dogfood 证据（用户首次真实使用，Hacker News 等）

用户确认以下路径**基本正常**（作为 REGRESSION_INVARIANTS，本轮不得破坏）：

1. 点击「不会」后：WordState 立即变为 learning；
2. 页面立即出现红色强提示；
3. learning 词正常进入生词本；
4. 生词本内能够进行掌握状态操作；
5. 当前 query dictionary 大部分查询路径正常。

同时暴露以下 6 个产品问题（本轮全部解决，不以只修 P0 结束）：

| # | 优先级 | 问题 | dogfood 表现 |
|---|---|---|---|
| 1 | P0 | **主机页原生交互冲突** | 透明 span + click 拦截（`preventDefault` + 弹菜单）与网页争夺 click/pointer/selection；HN 等链接页无法自然点开链接；button/checkbox/input/拖选/Cmd/Ctrl/Shift-click 存在同类风险 |
| 2 | P1 | **个性化提示失效** | 用户观察到简单词（如 `woman` 一类）被系统提示，而用户已在测评中通过更难的词——系统表现为「完全不认识我」。**表述边界**：user-observed symptom = TRUE；已核实的结构性事实 = 当前 hint 不消费 AssessmentEvidence（TRUE）；`woman` 具体为何出现灰线尚未在当前资产下复现（rank=111 < T₀=22662，按现行公式本不应提示），留待实现/验收阶段复现；该未复现个例不影响 personalized hint 产品决议 |
| 3 | P1 | **本地词典 miss 是死路** | miss 词只能看到「当前词典未收录」：无翻译、不能反馈会/不会、不能进生词本——明显半成品 |
| 4 | P1 | **测评/校准/重测 UX 不透明** | 产品设计者本人都不理解：初测 50 题、每日五题、calibration、estimate、manual 反馈的影响、重测清什么、入口在哪 |
| 5 | P2 | **全词可查显冗余** | 「每一个单词都能查」感觉冗余（影响不大）；modifier 门控后需验证是否自然解决 |
| 6 | P2 | **hint 密度/视觉质量** | 「稀疏」≠「合理」：误提示、密度、红/灰视觉层级、不同页面类型是否吵、是否破坏阅读节奏 |

## 3. PRODUCT_GOAL

让插件成为**可以长期挂在浏览器里使用的阅读工具**，三个最高层判断：

- **A（PAGE INTERACTION）**：插件永久启用时，用户在绝大多数时间可以忘记它的存在，直到自己主动按住 Ctrl 查词。
- **B（COVERAGE/FALLBACK）**：本地词典未收录一个普通英文词时，用户仍能完成「理解 → 判断会/不会 → 生词管理」闭环，不变成死路。
- **C（PERSONALIZATION）**：用户已通过足够测评证明掌握较简单词汇后，系统不再机械地给大量明显简单词画灰线。

同时保持：PRODUCT UX + DATA SEMANTICS + PRIVACY + ENGINEERING CLEANLINESS 同时成立，不牺牲任何一个来假装完成。

## 4. PAGE_NATIVE_INTERACTION_FIRST

**正文 click 所有权（网页）**：正文中任何 click（含链接导航）永远归网页/浏览器。插件**绝不** preventDefault / stopPropagation 正文交互；不因单词包装阻止网页 click；不抢占 button/checkbox/input/textarea/select/form submit/context menu/drag/text selection/Cmd-click/Ctrl-click/Shift-click。

**浏览器所有权**：浏览器自身定义的修饰键组合语义（Cmd-click 新标签、Ctrl-click 右键/新标签、Shift-click 选区等）保持原生，插件不得覆盖。

**Extension 所有权**：仅插件创建的 UI（tooltip、其内按钮、生词本/弹窗等）由插件管理；这些 UI 上的事件仅作用于插件自身。

**验收**：真实 Puppeteer keyboard/mouse 矩阵（§21），非仅 dispatchEvent。

## 5. MODIFIER_GATED_LOOKUP_STATE_MACHINE

### 5.1 状态

| 状态 | 含义 |
|---|---|
| IDLE | 无 Ctrl；**零查询/反馈交互 UI**（无 query tooltip、无 action/feedback UI）；所有网页交互原生；**passive hint decoration（light 灰线 / strong 红线）继续按 §7/§18 显示，不受 Ctrl gate 控制** |
| CTRL_ARMED | Ctrl 已按下；等待 hover 命中可查询词 |
| WORD_TOOLTIP | Ctrl 按住且指针悬停在 queryable word 上；显示查询 tooltip |
| TOOLTIP_INTERACTION_SESSION | 指针已进入 extension-owned tooltip；keyup 豁免生效；可普通点击会/不会 |
| CLOSED | tooltip 已关闭的**瞬态**——按当前 Ctrl 状态立即归一：Ctrl 仍按住 → CTRL_ARMED，已释放 → IDLE；**不得成为可卡住的稳定状态** |

### 5.2 事件转移（D1/D3/D6/D7 闭合）

| 事件 | 转移 |
|---|---|
| Control keydown | IDLE/CLOSED → CTRL_ARMED |
| pointer enter word（CTRL_ARMED 且 word queryable） | → WORD_TOOLTIP，显示 tooltip |
| pointer leave word（Ctrl 仍按住） | **relatedTarget 属于当前 tooltip → 不隐藏，转入 TOOLTIP_INTERACTION_SESSION（ownership 转移）；否则 → CTRL_ARMED，隐藏 tooltip** |
| Control keyup（指针不在 tooltip 内） | WORD_TOOLTIP/CTRL_ARMED → IDLE，隐藏 tooltip |
| pointer enter tooltip | WORD_TOOLTIP → TOOLTIP_INTERACTION_SESSION（豁免激活） |
| Control keyup（指针在 tooltip 内） | 保持在 TOOLTIP_INTERACTION_SESSION（**D3 有界例外，D7**） |
| pointer leave tooltip | TOOLTIP_INTERACTION_SESSION → **按当前 Ctrl 状态归一：按住 → CTRL_ARMED；已释放 → IDLE**（=CLOSED 瞬态），隐藏 tooltip |
| button click（tooltip 内 会/不会） | 写入状态（仅 WordState）；tooltip 关闭并按当前 Ctrl 状态归一（按住 → CTRL_ARMED；释放 → IDLE） |
| Escape | 任意状态 → 按当前 Ctrl 状态归一（=CLOSED 瞬态） |
| scroll / navigation / DOM removal（目标词消失） | 任意状态 → 按当前 Ctrl 状态归一（=CLOSED 瞬态） |
| 无 Ctrl 的任何 hover | 不产生查询 UI（IDLE 保持；passive hint decoration 不受影响） |

约束：不得产生永久 sticky tooltip；tooltip 会话只由「指针在 tooltip 内」维持，**不使用计时器**；word→tooltip 的 ownership 转移通过 `pointerleave` 的 `relatedTarget` 判断，不得依赖「tooltip 先收到 pointerenter」的时序巧合（无竞态）；tooltip 显示不拦截正文事件。

### 5.3 link-query 共存（D6）

链接文字内单词在 Ctrl+hover 下可查询；点击（含 Cmd/Ctrl/Shift/右键）保持链接原生行为。tooltip 与链接共存时，链接 click 不被 tooltip 或包装 span 拦截。

## 6. TOOLTIP_AND_FEEDBACK_INTERACTION

- tooltip 内容：页面词形（surfaceForm）、音标、词性、简短中文释义（query dictionary canonical entry；miss 词显示「当前词典未收录」）+ 「会 / 不会」按钮。
- **feedback 只发生在 extension-owned UI（tooltip 按钮）**；正文 click 永不用于 feedback（D6/D7）。
- 交互会话见 §5.2；按钮点击写入 `WordState`（known/learning，source=manual），**不写 AssessmentEvidence、不改估计**（继承规则）。
- tooltip 几何沿用既有规则（优先上方、必要时下方、不超视口、不侵入 sticky/header、滚动后定位正确）。
- 未收录词（lookup miss）的 tooltip：显示「当前词典未收录」+ 会/不会按钮（D10 允许反馈）。

## 7. PERSONALIZED_HINT_POLICY（D8/D18–D26 + 收口合同）

展示决策拆为两层：

1. **显式状态提示**（继承）：known → 不提示；learning → 红色强提示（同页首次含行内中文）。explicit known 永远不提示、explicit learning 走红色强提示（收口合同 1）。
2. **候选提示（light/灰线）——三层架构（D18）**：
   - **Global bootstrap**：个性化证据不足时的默认灰线阈值 = 现有 T₀（沿用 effectiveFrequencyRank 口径，公式保留为参数 seam）；
   - **Optional hint calibration**：可跳过、约 1 分钟、从更宽 query frequency rank 范围采样，估计 personal transition region / boundary（§9A/§9B）；与固定 1000 词词汇量测评**两个不同目的**；不进 estimate、不伪装 AssessmentEvidence、不自动创建 WordState；
   - **Real reading feedback**：阅读中 manual known/learning 的 query word（有有效 effectiveFrequencyRank）持续校准 personal boundary（§9C）。

**AssessmentEvidence 对 hint 仅两个有限作用（D18）**：① 已测词特例——该词 latest Evidence=known → 不提示；learning → 该词可提示（优先于 boundary）；② 保守 safety signal——基础 assessment 明显不稳定时避免过度隐藏提示。

**灰线判定（收口合同 1）**：personal hint boundary 从 transition region 较简单一侧确定性派生；**transition region 本身及更困难区域具备 gray-hint eligibility**（**word rank ≥ boundary** 才可能灰线；boundary = transition region 简单侧窗口内样本的最小 rank，见 §9B.1，故 transition region 整体被 `≥` 覆盖，与收口合同 1 完全一致）；queryability 不受 boundary 影响（boundary 只影响灰线候选，不影响查询/反馈）。

约束：候选不落盘、不改写 WordState；不恢复概率画像/PAV/Beta/高置信自动隐藏/Bayesian/IRT/SRS；hint-ineligible（无有效频率）词不参与灰线候选但保持可查询；manual 状态过滤保留（候选只作用于无显式反馈词）。

## 8. ASSESSMENT_EVIDENCE_BOUNDARY

- **Evidence MAY INFORM HINT POLICY（仅两个有限作用，见 §7），BUT MUST NOT CREATE / REWRITE WordState**（D8）。
- 估计仍只读 AssessmentEvidence（单点 + Wilson 保守范围，继承规则）；manual 反馈不进入估计分子/分母（继承）。
- 包外词 / 未收录临时键不写 Evidence、不进估计（继承 + D10）。
- **calibration 与 formal assessment 完全隔离（D18/D20）**：calibration 数据不写 AssessmentEvidence、不写 WordState、不进 vocabulary estimate、不伪装 WordState；calibration 持久化不与 Evidence 混存语义（收口合同 4）。
- 内容脚本不得把 Evidence 写入用户状态；候选生成前后 WordState snapshot 不变（负断言）。

## 9. RECENT_K_EVIDENCE（D16，用途收窄为 assessment 侧读取 seam）

D16 语义保留（**每词只留最新一条 Evidence、无测试 attempt 历史、派生视图、不升 schema**），用途按 D18 收窄：

- 已测词特例的读取（该词 latest Evidence 直接判定 known→不提示 / learning→可提示）；
- 保守 safety signal 的输入（**独立的「全 assessment 最近 5 个不同 wordKey 的最新 Evidence」派生视图**——safety-signal 专用 view，复用「每词 latest Evidence」事实，**非 D16 per-band window**——learning 占比高 → **effective boundary = min(personal boundary, T₀)**，不隐藏超过全局默认；predicate/effect 的确定性 bootstrap 见 §9B.1 safety signal 行；不恢复 band 外推、不写状态、不进估计）。

**不再**作为全量 query hint boundary 的主执行输入（D18 取代 band profile 主边界）。

## 9A. HINT_CALIBRATION_SAMPLING（D19/D20/D21）

- **入口与 UX**：popup「我的词汇水平」总览提供可选入口（可跳过）；「约 1 分钟」为 UX target 非固定 SLA（D21）。
- **答题**：每题三选一「会 / 不会 / 不确定」，语义固定（会＝基本能立即知道常见语境主要意思；不会＝不知道或没印象；不确定＝眼熟/大概知道但无把握）；UI 明确解释三选项标准；不需构造中文干扰项（D20）。
- **两阶段采样（D19）**：Stage 1 少量宽覆盖样本确定候选难度区域；Stage 2 候选区域内追加样本局部细化；均以 `effectiveFrequencyRank` 为难度排序轴。
- **预算（D21）**：总题量 hard cap = 20（Stage1+Stage2 总计 ≤ 20；分配 default 见 §9B.1）；用户随时可退出/跳过；证据不足 fail-safe 回退 T₀。
- 答案只属 calibration 数据；不写 WordState/Evidence、不进 estimate。

### 9A.1 V0.1 rank 采样 default（DOGFOOD_TUNABLE_PARAMETER，确定性）

**Universe**：U = 查询词典中所有有有效 `effectiveFrequencyRank` 的词，按 **(effectiveFrequencyRank ASC, wordKey ASC)** 升序排列（rank 1 = 最常用；wordKey 为稳定 tie-break，保证同 rank 词顺序确定，同一 snapshot 同一候选）；n = |U|（当前约 40k）。同一 dictionary snapshot 下 U 固定。

**Stage 1（宽覆盖粗定位，k₁ = 8 题）**：
- 在 U 中取**等距索引位置**：`p_i = floor((n − 1) · i / (k₁ − 1))`，i = 0..k₁−1（即第 0、n/7、2n/7、…、n−1 位），取对应 wordKey 作为题目；
- 全范围覆盖、无随机、无在线模型；同一 snapshot 同一候选。

**Stage 1 估计**：对 Stage 1 答案运行 §9B 的 transition-region estimator，得到初步 transition band [rank_lo, rank_hi]；**三分支确定性处理（单一确定默认，无二义）**：
1. 存在 TRANSITION 窗口 → band = 选中的 TRANSITION run 覆盖的 rank 区间（run 选择见 §9B.2）；
2. 无 TRANSITION 但存在 KNOWN/LEARNING 交界 → band = 交界处相邻窗口（简单侧最后一个 KNOWN_DOMINANT 窗口与困难侧第一个 LEARNING_DOMINANT 窗口）之间的 rank 区间（仍确定性）；
3. 全部 KNOWN_DOMINANT **或**全部 LEARNING_DOMINANT（既无 TRANSITION 也无两类交界）→ **calibration 未定位成功：不进入 Stage 2，直接按 fail-safe 结束，不生成 personal boundary，回退 T₀**（§9B.2 第 4 条同一语义）。

**Stage 2（候选区细化，k₂ = min(12, 20 − 已答数) 题）**：
- 候选集 C = U 中 rank ∈ [rank_lo, rank_hi] 且未答过的词；若 |C| < k₂，按「先最低 rank、再最高 rank、交替向外」确定性扩展至恰好 k₂ 个（或耗尽）；
- 在排序后的 C 中等距取索引：`q_j = floor((|C| − 1) · j / (k₂ − 1))`，j = 0..k₂−1，跳过已答 wordKey；
- **fail-safe**：候选耗尽（|C| < k₂ 且无可扩展未答词）→ 用尽当前样本结束；若最终未达最小可信证据（§9B 收口合同 2）→ 不生成 personal boundary，回退 T₀。

全部标 **DOGFOOD_TUNABLE_PARAMETER**（k₁/k₂ 分配、等距取点、扩展方向）。

## 9B. TRANSITION_REGION_ESTIMATOR（D22–D26 + 收口合同 1/2）

- **框架（D22）**：估计 personal transition region / boundary band（不假设绝对单调）；uncertain = 最直接 boundary-location signal（不=learning、不丢弃、非普通第三类、非 hard veto）；known/learning = 区域趋势证据而非单词级硬约束；容忍 rank inversion。
- **局部窗口（D23）**：已答样本按 effectiveFrequencyRank 升序；按样本数量定义的局部滑动窗口观察局部回答结构（非固定 rank bin）；单个 inversion/异常/误操作不直接决定 boundary；deterministic/reproducible。
- **窗口分类（D24/D25/D26）**：默认 TRANSITION；仅当 **directional dominance ∧ uncertainty gate 同时满足**（比例形式）才判 KNOWN_DOMINANT / LEARNING_DOMINANT；其余（含 K/L 混合、U 集中、三答混杂）保持 TRANSITION；单个 U 不自动 veto、U 局部集中可阻止表面 dominance。
- **transition region → boundary（收口合同 1）**：transition region = **选中的 TRANSITION run**（§9B.2 确定性 run 选择：窗口数最多、并列取 rank 最低、无 run 回退 T₀）覆盖的 rank 区域；personal hint boundary 从该区域**较简单一侧**确定性派生；transition region 本身及更困难区域具备 gray-hint eligibility（word rank ≥ boundary，§7/§9B.1 统一语义）；精确端点/代表点为 DOGFOOD_TUNABLE_PARAMETER（只要求 deterministic）。
- **最小可信证据与提前结束（收口合同 2）**：须同时观察到 transition region 及其至少一侧稳定趋势证据才生成 personal boundary；不足/高度矛盾 → 回退 T₀；追加样本不再改变 transition region 且满足可信证据 → 可提前结束；总题量 ≤ 20；最小样本数/连续稳定轮数为 DOGFOOD_TUNABLE_PARAMETER；实现必须确定性、可测试（禁止「感觉已收敛」）。

### 9B.1 V0.1 bootstrap defaults（DOGFOOD_TUNABLE_PARAMETER，非永久产品规则）

以下为满足已确认 canonical examples 的最小确定性 defaults，全部标记 **DOGFOOD_TUNABLE_PARAMETER**（dogfood 后可调整，不得写成永久 SLA）：

| 参数 | bootstrap（default） | 验证的 canonical examples / 依据 |
|---|---|---|
| window size w | 5 | — |
| directional dominance 比例 p | 0.6（|known−learning|/w ≥ p） | `K K K K L`（0.6）→ KNOWN_DOMINANT；`K K K L L`（0.2）→ TRANSITION |
| uncertainty gate 比例 q | 0.4（uncertain/w ≥ q → TRANSITION） | `K K K U U`（0.4）→ TRANSITION；`K K K K U`（0.2）→ KNOWN_DOMINANT（单 U 不 veto） |
| Stage1/Stage2 分配 | default = 8 / 12（§9A.1 k₁/k₂） | 两阶段结构 |
| rank 采样 | §9A.1 等距索引取点（Stage1 全范围 / Stage2 候选区） | 确定性、可复现、无随机 |
| 最小可信证据 | ≥ 12 个有效答案，且 transition region **至少一侧** ≥ 1 个稳定趋势窗口（KNOWN_DOMINANT 或 LEARNING_DOMINANT） | 收口合同 2 / R-CAL-5（「至少一侧」） |

| safety signal（assessment 不稳定 guard） | predicate：**独立的「全 assessment 最近 5 个不同 wordKey 的最新 Evidence」派生视图**（safety-signal 专用 view：按 `assessedAt` 降序取全局最近 5 个不同 key 的最新 Evidence，仅复用「每词 latest Evidence」事实；**不是 D16 per-band window，亦无多 band 聚合问题**）中 learning ≥ 3/5（≥60%）→ 判定「明显不稳定」；effect：**effective boundary = min(personal boundary, T₀)**（不隐藏超过全局默认；assessment 稳定时无 clamp）；Evidence 清空 → 视图自然为空 → guard 自然失效 | D18/R-HINT-3：保守 guard、不恢复 band 外推、不写状态、不进估计 |

### 9B.2 V0.1 TRANSITION run 选择 default（DOGFOOD_TUNABLE_PARAMETER，确定性）

rank inversion（D22/D23）下，窗口序列可能出现多个不连续 TRANSITION run（如 `TRANSITION → LEARNING_DOMINANT → TRANSITION`）。选择规则为单一确定默认（同一输入同一输出）：

1. **枚举**：按 rank 升序枚举所有由**连续 TRANSITION 窗口组成的最大 run**（相邻 TRANSITION 窗口归入同一 run，被非 TRANSITION 窗口隔断即视为新 run）；
2. **选择**：覆盖**窗口数最多**的 run 作为 personal transition region；
3. **并列 tie-break**：窗口数相同时，取 **rank 最低（更简单侧）** 的 run；
4. **无 run fail-safe**：不存在任何 TRANSITION run → **无可信 transition region：不生成 personal boundary，回退 T₀**（与 §9A.1 Stage 1 三分支 ③ 同一语义）；
5. **单一消费**：Stage 2 候选区（§9A.1）、boundary 派生（§9B.1）、提前结束（§9B.1）必须全部消费**同一个**选中的 run，保证结果唯一。

## 9C. REAL_READING_FEEDBACK_CALIBRATION（收口合同 3）

- manual known/learning 的 query word 若有有效 `effectiveFrequencyRank` → 长期 personalization evidence；
- 单个 manual answer 不得让 boundary 大幅跳变（通过 transition-region 思路重新派生，而非单点重算）；
- explicit WordState 永远优先，聚合模型不得反写 WordState；
- 无 frequency rank 的 manual state 对该词本身有效，但不参与 rank-boundary calibration；
- 数据不足时保持上一个可信 boundary；从未形成可信 boundary → 回退 T₀。

## 9D. CALIBRATION_PERSISTENCE（收口合同 4）

- personal calibration 重启后继续有效；重新完整执行 calibration 可替换旧 baseline；manual reading feedback 继续在此基础上更新；
- 不与 AssessmentEvidence 混存语义、不进 estimate、不伪装 WordState；
- 实现前调查当前 schema/storage：能在现有 schema 3 / 兼容存储边界内实现 → 最小方案；真正需要 bump profile schemaVersion → **SCHEMA_CHANGE_REQUIRED STOP 返回用户**；不得为避免 STOP 把 calibration 数据塞进语义不匹配的旧字段。

## 10. UNRESOLVED_TOKEN_IDENTITY_AND_MANUAL_STATE（D10）

- **词典可解析性 ≠ 用户反馈资格**：本地查询词典 miss 的普通英文 token 允许：反馈会/不会、进入生词本。
- **临时身份**：状态键 = 规范化 surface token（trim、去首尾标点、小写、去空白）；是字符串键，**不升级 schema**（与 F 一致）。
- **manual 状态资格**：miss 词可写 `WordState`（known/learning，source=manual）。
- **Evidence 隔离**：miss 词不写 AssessmentEvidence（无 band，估计天然跳过）。
- **生词本未收录元数据**：popup 生词本中该类条目如实标注「未收录」（展示层 re-resolve：当前词典仍无法解析则显示标注；解析后按 §11 升级）。
- **拖选辅助入口**：维持既有规则（拖选未收录 → 无法唯一解析 → 静默不弹）；未收录词的 notebook 主入口为 tooltip 会/不会（D10 主交互路径），拖选辅助入口不扩大。
- **历史无法解析键**：保守保留，不静默删除（继承）。

## 11. CANONICAL_RECONCILIATION（D17）

- **惰性迁移触发**：当持有 `WordState` 的 surface key 被查询词典解析到 canonical lemma（词典更新后 lookup 命中，如 `womans`→`woman`）时，一次性迁移。
- **迁移动作**：把该 surface key 的 `WordState` 移到 canonical wordKey；删除 surface key；幂等（重复触发无副作用）。
- **碰撞仲裁**（canonical 已有 `WordState` 时，复用 schema 3 既有规则，非新发明）：`updatedAt` 较新者胜 → 相同则 manual 优先 → 仍相同则 learning 优先（避免漏提示）。
- **未解析保留**：仍无法解析的历史 surface key 保守保留。
- **迁移边界**：只迁 `WordState`；**不创建 AssessmentEvidence、不升 schema**。
- **跨标签同步**：迁移后 canonical 词状态经既有 STATE_UPDATED 广播同步。
- **生词本去重**：迁移后每词一键，天然去重；「未收录」标注在解析后自动升级为完整元数据展示。
- **触发位置**（实现 seam）：内容脚本 lookup 命中路径 / popup 生词本遍历路径均可触发，均为读路径幂等操作。

## 12. LOOKUP_FALLBACK（D11）

- **local-first**：本地查询词典命中 → 立即本地查询。
- **local miss → remote（用户主动、单词级、按需）**：
  - 只允许在**用户主动发起查询**（Ctrl+hover 显示 tooltip 且词 miss）时触发；
  - 只发送**当前 word/token**；
  - 不发送网页正文、URL、页面标题、整句或浏览历史（默认禁止）。
- **降级**：离线或失败 → 明确提示「未收录，且当前无法获取网络释义」；不静默失败。
- **Provider 未选择**：本 Spec 不选择 provider、不预设 API、不写死域名（§13/§25，implementation-before-STOP）。
- **identity 边界（负断言）**：远程 provider 返回的 lemma/metadata 默认只作 lookup/translation display/cache metadata，**不得自行迁移或改写 WordState identity**；D17 canonical reconciliation 只由已批准 query dictionary 的本地 resolution 触发；若未来要让 provider lemma 改变 wordKey，须单独用户确认（STOP_CONDITION: PRODUCT_DECISION_REQUIRED）。

## 13. NETWORK_PRIVACY_BOUNDARY

- 禁止上传：页面正文、整句、URL、标题、浏览历史（任何 provider 下都禁止，负断言）。
- 只允许传输：单个 miss word/token（用户主动触发时）。
- provider、域名权限、API 许可、缓存再分发许可、大陆网络可用性在 **research + 用户确认前**：不建生产网络实现、不加入泛化 `host_permissions`（fail-closed）。
- 不新增遥测/日志/dashboard（继承）。

## 14. CACHE_AND_PERSISTENCE

- 抽象合同（不冻结具体格式/存储）：若 provider 许可允许，可本地缓存 miss 词的远程释义（单词语义级）；若 provider 许可不允许缓存，不得缓存。
- **provider research 前不冻结 cache format / 缓存表 / schema**；缓存内容不得包含上下文。
- 缓存许可判定为 implementation-before-STOP 项（§25/§26）。

## 15. NOTEBOOK_BEHAVIOR

- learning 词进入生词本；known/「已掌握」移除（继承）。
- 展示所有 `status=learning` 且可展示元数据的 identity（含测评包外词，继承）+ 未收录临时键条目（标注「未收录」，D10）。
- canonical reconciliation 后（§11）：条目去重、标注自动升级。
- 生词本只读 WordState；不读 AssessmentEvidence（继承）。
- 历史无法映射 key 保守保留、不展示、不删除（继承）。

## 16. ASSESSMENT_CALIBRATION_RETEST_UX（D12/D13/D18–D21）

- **首测**：50 题、十频段各五题（继承）；完成前不出现每日入口（继承）。
- **每日校准**：每日五题、奇偶频段轮换（继承）；daily 作答写入 AssessmentEvidence → 只服务「已测词特例 + 保守 safety signal」（D18），不再作为全量 hint boundary 主输入。
- **提示校准（optional hint calibration，D18–D21）**：popup「我的词汇水平」总览提供**可跳过**的「提示校准」入口（与正式词汇量测评两个目的，UI 明确区分）；「约 1 分钟」为 UX target 非 SLA；总题量 hard cap 20（两阶段采样 §9A）；每题三选一「会/不会/不确定」并解释三选项标准；不写 WordState/Evidence、不进 estimate；证据不足 fail-safe 回退 T₀；UI 说明「提示校准只用于决定灰线从哪里开始，不影响词汇量估计」。
- **重新完整测评 = 半重置（D12）**：清空 AssessmentEvidence、dailyTest、completedRoundIndex（估计从新证据重新积累；新证据不足时 estimate=unavailable）；**保留全部 WordState**（生词本、manual learning/known 不丢）；重测作答仍按现行「后写覆盖」写入同词状态；入口带确认对话框与解释文案。
- **popup「我的词汇水平」总览（D13）**：首测状态 / 点估计 / 保守范围 / 今日校准进度（0/5）/ 最近校准 / [开始今日校准] / [重新完整测评]（带确认）/ [提示校准]（可跳过）+ 一行解释「手动标记的会/不会只影响阅读提示和生词本，不会伪装成正式测试成绩」；「了解这些数字」可展开说明（默认收起，按需解释估计/校准/提示校准/重测语义）。

## 17. EVERY_WORD_QUERYABILITY（D14）

- 保留广覆盖查询词典；所有 queryable 词默认可 Ctrl+hover 查询（invisible capability：无 Ctrl 时零查询/反馈交互噪声；**passive hint decoration 仍按 §7/§18 显示，不受 Ctrl gate 控制**）。
- **不重新绑定 queryability 与 hint eligibility**；不因冗余感收缩查询面；不提前优化。

## 18. HINT_DENSITY_AND_VISUAL_POLICY（D15）

- 验收 = 结构化测量 + 人工 dogfood，**不冻结未经验证的固定 SLA**：
  - 每百词灰线密度（perf seam 输出参考值）；
  - learning 强提示数；
  - 人工三数字（不必要提示 / 释义不可用 / 覆盖缺失，继承 dogfood 记录规则）；
  - 按页面类型（HN / 长文 / 文档 / 论坛）分别记录。
- 数据积累后由用户判断是否调整算法参数（K、边界）；不先调颜色掩盖算法问题。

## 19. SCHEMA_AND_MIGRATION

- **目标：schema 3 不变**。
- D16 = Evidence map 的派生视图（§9，assessment 侧读取 seam），无新增持久化。
- D17 = 惰性状态迁移（§11），无 schema 变更。
- **calibration 持久化（收口合同 4）**：优先在现有 schema 3 / 兼容存储边界内实现（重启有效、重校准替换 baseline、reading feedback 更新、不与 Evidence 混存）；实现前调查；**若实现证明 schema bump 必需**：STOP，返回用户重新决策（STOP_CONDITION: SCHEMA_CHANGE_REQUIRED）；不得为避免 STOP 把 calibration 数据塞进语义不匹配的旧字段。
- 既有 schema 3 迁移与仲裁规则不变（继承）；快照隐私约束不变（无 URL/正文/句子/历史）。

## 21. REAL_CHROME_ACCEPTANCE（P0 最高 gate）

**必须使用真实 Puppeteer keyboard/mouse 路径，不得仅 dispatchEvent**。覆盖：

- **ANCHOR**：普通 click / Cmd-click / Ctrl-click / Shift-click / right-click —— 保持浏览器原生行为（浏览器自身定义的特殊组合不得覆盖）。
- **BUTTON**：真实 mouse click。
- **FORM**：input focus/typing、textarea focus/typing、checkbox、radio、select、submit。
- **TEXT**：drag selection、copy、context menu。
- **SCROLL**：wheel/scroll。
- **PLUGIN**：Ctrl keydown → hover queryable word → tooltip 出现；Ctrl keyup → tooltip 消失；无 Ctrl hover → 无查询 UI。
- **LINK QUERY（D6）**：链接文字 Ctrl+hover 查询可用 + 链接原生 click 保持完好。
- **TOOLTIP 会话（D7）**：pointer 移入 tooltip → keyup 豁免 → 松开 Ctrl 点击按钮写状态 → 移出关闭。
- **未收录（D10）**：miss 词 tooltip 显示「未收录」+ 会/不会可写状态；不写 Evidence。
- **迁移（D17）**：预置 surface learning → 词典更新解析 → 惰性迁移到 canonical、surface 删除、红提示/生词本连续。
- **重测（D12）**：半重置后 Evidence 清空、WordState 保留、估计 unavailable→重新 available。
- **hint（D18/D22–D26）**：calibration 三选一流程可完成/可跳过/20 题 cap；transition-region 估计的 canonical examples（`K K K L L`→TRANSITION、`K K K K L`→KNOWN_DOMINANT、`K K K U U`→TRANSITION、单 U 不 veto）；boundary 派生后 transition region 及更困难区域灰线、explicit known 不提示；WordState 零改写。
- **reading feedback（收口合同 3）**：manual known/learning 持续校准 boundary；单次反馈不造成大幅跳变；无 rank 的 manual state 不影响 rank-boundary。

- R-INT-5：正文 click 归网页，绝不 preventDefault/stopPropagation，不破坏 Cmd/Ctrl/Shift/右键（D4/D6）
- R-INT-6：链接/interactive 内文本可 Ctrl+hover 查询，与原生 click 共存（D6）
- R-INT-7：tooltip 为 extension-owned 交互 UI；feedback 只发生在 tooltip（D7）
- R-INT-8：状态机（IDLE/CTRL_ARMED/WORD_TOOLTIP/TOOLTIP_INTERACTION_SESSION/CLOSED 瞬态）与事件转移（§5.2；CLOSED 按 Ctrl 归一、word→tooltip relatedTarget ownership 转移，无死状态/无竞态）

### R-HINT（提示）
- R-HINT-1：Evidence 可影响 hint policy 但不创建 WordState（D8）
- R-HINT-2：三层 hint 架构——Global bootstrap（T₀ 兜底）/ Optional hint calibration / Real reading feedback（D18）
- R-HINT-3：AssessmentEvidence 对 hint 仅两个有限作用：已测词特例 + 保守 safety signal（D18）
- R-HINT-4：K 窗口 = 最近 K 个不同 wordKey 最新 Evidence（assessedAt 降序），无历史、不升 schema；用途收窄为 assessment 侧读取 seam（D16/D18）
- R-HINT-5：K 参数化，bootstrap=5，dogfood 可调（D9/D16）
- R-HINT-6：manual 状态过滤优先；候选不落盘（继承）
- R-HINT-7：transition region 及更困难区域具备 gray-hint eligibility；explicit known 不提示、learning 走红色；已测词特例优先；queryability 不受 boundary 影响（收口合同 1）
- R-HINT-8：real reading feedback 持续校准——单次反馈不大幅跳变；WordState 永远优先、聚合不反写；无 rank 的 manual state 不参与 rank-boundary（收口合同 3）

### R-CAL（提示校准）
- R-CAL-1：calibration 可跳过；「约 1 分钟」为 UX target 非 SLA；总题量 hard cap = 20（D18/D21）
- R-CAL-2：两阶段采样（Stage1 宽覆盖粗定位 + Stage2 候选区细化），以 effectiveFrequencyRank 为难度排序轴（D19）
- R-CAL-3：每题三选一「会/不会/不确定」，三选项语义固定；UI 解释三选项标准；不需中文干扰项（D20）
- R-CAL-4：transition-region estimator——局部滑动窗口（样本计数窗口）；默认 TRANSITION；双条件 dominance（directional dominance ∧ uncertainty gate，比例形式）；容忍 rank inversion（D22–D26）
- R-CAL-5：最小可信证据与提前结束——须同时观察到 transition region 及至少一侧稳定趋势证据；不足/矛盾回退 T₀；稳定后可提前结束；总题量 ≤ 20（收口合同 2）
- R-CAL-6：calibration 数据隔离——不写 AssessmentEvidence/WordState、不进 estimate、不伪装 WordState（D18/D20）
- R-CAL-7：Persistence——重启后有效、重校准替换 baseline、reading feedback 继续更新、不与 Evidence 混存；schema 3 优先，需 bump 时 SCHEMA_CHANGE_REQUIRED STOP（收口合同 4）
- R-CAL-8：bootstrap 参数（window size/p/q/题量分配/最小样本/提前结束轮数/boundary 端点）为 DOGFOOD_TUNABLE_PARAMETER，Spec 给出 defaults，dogfood 可调（收口合同 1/2）

## 25. OPEN_DECISIONS

- **PROVIDER_SELECTION = DEFERRED_WITH_IMPLEMENTATION_STOP**：本 Spec 不选择 fallback provider；research（API/许可/成本/大陆网络可用性/rate limit/缓存再分发许可）后由用户确认；确认前不建生产网络实现、不加泛化 `host_permissions`。**不因该 deferred 项阻塞本 Spec 的 DOCUMENT review。**
- **DOGFOOD_TUNABLE_PARAMETER（非产品 policy，不阻塞）**：window size=5、dominance 比例 p=0.6、uncertainty gate 比例 q=0.4、Stage1/Stage2 分配 8/12、**rank 采样（§9A.1 等距索引取点 + `(effectiveFrequencyRank, wordKey)` 稳定 tie-break）**、**TRANSITION run 选择（§9B.2：窗口数最多、并列取 rank 最低、无 run 回退 T₀）**、最小可信样本 ≥12、提前结束连续稳定轮数 3、boundary 端点取法、**safety-signal 阈值与「全 assessment 派生视图」（§9B.1：全局最近 5 个不同 key、learning ≥3/5、effect=min(personal, T₀)）**——由 §9A.1/§9B.1/§9B.2 给出 bootstrap defaults（满足全部 canonical examples），dogfood 后可调整；**不冻结为不可变 SLA**。
- **calibration 持久化实现细节**：实现前调查当前 schema/storage，优先在 schema 3 内实现；真正需要 bump → SCHEMA_CHANGE_REQUIRED STOP 返回用户（收口合同 4）。
- **hint density = measurement only**（无固定阈值）。
- 无其他阻塞性 OPEN；核心产品 policy 已由 D1–D26 与四组收口合同闭合。

## 26. STOP_CONDITIONS

- **PROVIDER_DECISION_REQUIRED**：进入网络实现前 provider 未确认 → STOP。
- **PRODUCT_DECISION_REQUIRED**：若未来要让 remote provider lemma 改写 WordState identity（非本地 query dictionary resolution）→ STOP 返回用户（§12 identity 边界）。
- **NETWORK_PERMISSION_DECISION_REQUIRED**：加入远程权限前未获用户批准 → STOP。
- **CACHE_LICENSE_DECISION_REQUIRED**：缓存格式/再分发未获 provider 许可确认 → STOP。
- **SCHEMA_CHANGE_REQUIRED**：实现证明 schema bump 必需 → STOP 返回用户。
- **PRIVACY_BOUNDARY_CONFLICT**：任何要求上传上下文/URL/历史的方案 → STOP。
- **MAIN_BASELINE_MOVED**：交付前 origin/main 规则出现真实冲突 → STOP 报告。
- **RULES_SPEC_CONFLICT**：实现与 RULES/本 Spec 冲突且未获用户确认 → STOP。
- **P0_NATIVE_INTERACTION_UNRESOLVED**：P0 矩阵（§21）未全部通过前 → 不合并/不交付。
