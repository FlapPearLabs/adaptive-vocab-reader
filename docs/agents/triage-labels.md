# Triage 标签

| Skill 角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者检查和分类 |
| `needs-info` | `needs-info` | 信息不足，等待补充 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，AI 代理可执行 |
| `ready-for-human` | `ready-for-human` | 需要人工判断或操作 |
| `wontfix` | `wontfix` | 决定不处理 |

当 Skill 使用规范角色名称时，必须读取本表并使用对应 GitHub 标签。
